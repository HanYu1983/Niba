## 一、留學背景

### 1.1 報名動機

艾琳娜出生於中央王國普通魔法家庭，自幼展現魔法天賦，進入奧術之塔學習。她對東方文化充滿好奇的原因：

| 原因 | 說明 |
|------|------|
| **文化好奇** | 從小聽聞東方修仙傳說，對劍修文化充滿好奇 |
| **學術興趣** | 對「氣」與「瑪那」的本質差異產生學術興趣 |
| **梅林迪斯影響** | 院長梅林迪斯的「萬法同源」理論啟發了她 |
| **冒險精神** | 性格勇敢開朗，渴望探索未知世界 |

### 1.2 選拔過程

| 階段 | 說明 | 結果 |
|------|------|------|
| **初選** | 奧術之塔內部報名，數百人競爭 | 艾琳娜以優異成績入圍 |
| **複選** | 魔法理論考試 + 實戰測試 | 艾琳娜展現出色適應力 |
| **面試** | 梅林迪斯親自面試，評估文化交流潛力 | 艾琳娜通過面試 |
| **最終選拔** | 綜合評估，選出首批交流使者 | 艾琳娜成為西方使者之一 |

  - 試劍台上初見蜀山弟子練劍，被劍道之美震撼
