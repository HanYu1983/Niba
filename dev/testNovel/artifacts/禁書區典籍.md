### 禁書區典籍
| 項目 | 內容 |
|------|------|
| **等級** | 特殊（史詩階~傳說階） |
| **類型** | 魔法典籍 |
| **持有者** | 禁書區 |
| **煉製者** | 歷代院長 |
| **說明** | 禁書區收藏危險魔法典籍，非院長許可不得外傳。 |

#### 外觀說明
禁書區典籍形態各異，有的厚重如磚，有的輕薄如紙，但每一本都散發著危險的魔法氣息。封面多以黑色或深紅色裝幀，表面刻滿了禁忌魔法的封印符文，符文以暗紅色靈漆填充，散發著不祥的光芒。當禁忌魔法啟動時，典籍會自動翻開，頁面上的禁忌符文會亮起，投射出危險的魔法模型，周圍空氣因魔法波動而微微扭曲。

#### 文生圖提示詞
4K電影劇照風格，一本深紅色禁書區典籍靜置於禁書區的鐵製書架上，封面禁忌魔法封印符文閃爍暗紅光芒，典籍自動翻開頁面禁忌符文亮起投射出危險魔法模型，周圍空氣因魔法波動而微微扭曲，背景是陰暗的禁書區，燭光搖曳，戲劇性光影，超寫實渲染，電影級構圖，東方仙俠美學，8K解析度
