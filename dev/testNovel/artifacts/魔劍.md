### 魔劍
| 項目 | 內容 |
|------|------|
| **等級** | 玄階（融合） |
| **類型** | 魔劍類法寶 |
| **持有者** | 魔劍堂弟子 |
| **煉製者** | 器堂弟子 |
| **說明** | 魔劍堂弟子標配魔劍，可承載靈魔能量。 |

#### 外觀說明
魔劍全長三尺，劍身以靈魔雙色的精鋼鍛造而成，通體呈現暗灰色澤，劍刃邊緣泛著淡淡的藍紫色光芒。劍格處鑲嵌著一顆小型的靈魔雙色寶石，左半邊呈現靈氣的青色，右半邊呈現魔力的紫色。當靈魔承載啟動時，劍身會泛起藍紫色的劍芒，周圍空氣因靈魔能量波動而微微震顫，劍身表面浮現出靈魔符文。

#### 文生圖提示詞
4K電影劇照風格，一把暗灰色魔劍橫置於魔劍堂弟子的劍架之上，劍刃邊緣泛著藍紫色光芒，劍格靈魔雙色寶石散發青紫雙色光，劍身泛起藍紫色劍芒，表面靈魔符文若隱若現，背景是魔劍堂的修煉室，牆上掛著靈魔劍譜，燭光搖曳，戲劇性光影，超寫實渲染，電影級構圖，東方仙俠美學，8K解析度

#### 法寶能力
| 能力 | 說明 |
|------|------|
| **靈魔承載** | 承載靈魔能量，提升攻擊力 |
| **元素附魔** | 瞬間附著元素屬性 |
| **魔劍認主** | 認主後威力提升 |
