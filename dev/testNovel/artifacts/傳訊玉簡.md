### 傳訊玉簡
| 項目 | 內容 |
|------|------|
| **等級** | 玄階 |
| **類型** | 通訊法寶 |
| **持有者** | 內門弟子以上、交流使者 |
| **煉製者** | 器堂首座 |
| **說明** | 遠程通訊法寶，可跨地域傳遞訊息與影像，是東西方法術交流的重要工具。 |

#### 外觀說明
傳訊玉簡長約三寸，寬一寸，厚半寸，以淡綠色靈玉精雕細琢而成，形制古樸典雅。玉簡表面刻滿了細密的通訊陣紋，符文如蟻足般精密排列。玉簡一端鑲嵌著一顆米粒大小的傳訊晶石，平時呈現暗淡的綠色，通訊時會亮起明亮的光芒。當影像傳輸啟動時，玉簡會投射出半透明的立體影像，影像清晰如實物，色彩鮮明，聲音同步傳遞。

#### 文生圖提示詞
4K電影劇照風格，一枚淡綠色靈玉簡靜置於書案之上，表面通訊陣紋閃爍著微光，一端傳訊晶石亮起明亮綠光，玉簡上方投射出半透明的立體影像，影像中隱約可見人物輪廓，背景是古色古香的書房，書架上擺滿典籍，窗外月光灑入，戲劇性光影，超寫實渲染，電影級構圖，東方仙俠美學，8K解析度

#### 法寶能力
| 能力 | 說明 |
|------|------|
| **遠程傳訊** | 跨地域傳遞文字訊息，即時通訊 |
| **影像傳輸** | 高階玉簡可傳輸動態影像，如同面對面交談 |
| **神魂綁定** | 與使用者神魂綁定，他人無法竊聽 |
| **訊息儲存** | 可儲存大量訊息，方便隨時查閱 |
| **群組通訊** | 可設定群組，多人同時通訊 |
| **緊急呼叫** | 緊急情況下可強制喚醒接收者 |

#### 通訊距離
| 距離 | 說明 | 延遲 |
|------|------|------|
| **宗門內** | 蜀山山脈範圍內 | 即時 |
| **神州境內** | 神州大陸範圍 | 數息延遲 |
| **跨大陸** | 東西兩界通訊 | 數刻延遲 |
| **跨界通訊** | 靈魔兩界通訊 | 數辰延遲 |

#### 獲取方式
- **貢獻點兌換**：800 貢獻點
- **交流使者配備**：東西方法術交流使者標配
- **任務獎勵**：完成重大通訊任務後贈送

#### 使用限制
| 限制 | 說明 |
|------|------|
| **魂力消耗** | 每次通訊消耗少量魂力，長距離消耗較大 |
| **冷卻時間** | 跨界通訊後需冷卻時辰，避免過度使用 |
| **干擾因素** | 強烈靈氣風暴或魔法風暴可能干擾通訊 |
| **境界要求** | 築基期以上方可使用，煉氣期需長老協助 |
