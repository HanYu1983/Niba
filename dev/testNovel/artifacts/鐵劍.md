### 鐵劍
| 項目 | 內容 |
|------|------|
| **等級** | 黃階 |
| **類型** | 劍類法寶 |
| **持有者** | 外門弟子 |
| **煉製者** | 器堂雜役 |
| **說明** | 外門弟子標配鐵劍，基礎修煉用。 |

#### 外觀說明
鐵劍全長二尺八寸，劍身以普通精鋼鍛造，表面呈現暗灰色澤，未經靈力淬鍊，質地堅硬但略顯粗糙。劍格簡單樸素，以鐵片彎折而成，劍柄纏繞著防滑的麻繩。雖然外觀平凡，但劍身經過器堂雜役的精心打磨，劍刃依然鋒利。當靈氣注入時，劍身會泛起微弱的白色光芒，雖不華麗卻足以輔助基礎劍法修煉。

#### 文生圖提示詞
4K電影劇照風格，一把暗灰色鐵劍斜插於外門練劍場的木製劍架之上，劍身質樸無華，劍柄麻繩纏繞，劍刃在陽光下反射出微弱白光，背景是簡樸的練劍場，數十把相同的鐵劍排列整齊，遠處可見外門弟子練劍的身影，清晨的薄霧籠罩山間，戲劇性光影，超寫實渲染，電影級構圖，東方仙俠美學，8K解析度
