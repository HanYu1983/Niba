### 靈魂聖器
| 項目 | 內容 |
|------|------|
| **等級** | 傳說階 |
| **類型** | 治癒物品 |
| **持有者** | 院長 |
| **煉製者** | 歷任院長 |
| **說明** | 修復靈魂的聖器，可修復重度靈魂損傷。 |

#### 外觀說明
靈魂聖器呈聖杯之形，高約八寸，以純粹的靈魂能量與聖光融合凝結而成，通體呈現璀璨的白金色澤。聖杯表面刻滿了靈魂修復與本源修復的古老符文，符文以金色靈漆填充，散發著神聖的光芒。當靈魂修復啟動時，聖杯會爆發出耀眼的白金色光芒，光芒中浮現出靈魂本源的影像，如同金色的泉水般注入使用者的靈魂。

#### 文生圖提示詞
4K電影劇照風格，一座白金色靈魂聖杯矗立於院長密室的祭壇之上，表面靈魂修復符文閃爍金光，爆發耀眼白金色光芒，光芒中浮現靈魂本源影像如同金色泉水注入，背景是莊嚴的院長密室，燭光與聖光交相輝映，戲劇性光影，超寫實渲染，電影級構圖，東方仙俠美學，8K解析度

#### 物品能力
| 能力 | 說明 |
|------|------|
| **靈魂修復** | 修復重度靈魂損傷 |
| **本源修復** | 修復靈魂本源層損傷 |
| **輪迴感知** | 感知輪迴印記狀態 |

#### 獲取方式
- **院長許可**：只有院長許可方可使用
- **緊急情況**：靈魂重度損傷時可使用
