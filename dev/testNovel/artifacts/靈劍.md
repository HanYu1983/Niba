### 靈劍
| 項目 | 內容 |
|------|------|
| **等級** | 玄階 |
| **類型** | 劍類法寶 |
| **持有者** | 內門弟子 |
| **煉製者** | 器堂弟子 |
| **說明** | 內門弟子標配靈劍，可承載劍氣。 |

#### 外觀說明
靈劍全長三尺，劍身以精鋼為骨，表面鍍有一層薄薄的靈力薄膜，呈現淡青色澤。劍刃鋒利，透光可見內部細密的靈力紋路，如同樹木的年輪般層層疊疊。劍格處鑲嵌著一顆綠色的靈石，散發著溫和的光芒。當劍氣催動時，劍身會泛起青色的劍芒，周圍空氣因靈力波動而微微震顫，劍鳴聲清脆悅耳。

#### 文生圖提示詞
4K電影劇照風格，一把淡青色靈劍橫置於修煉室的劍架之上，劍身靈力紋路清晰可見，劍格處綠色靈石散發溫和光芒，劍刃泛起青色劍芒，周圍空氣因靈力波動而微微震顫，背景是簡潔的內門弟子修煉室，牆上掛著劍譜，晨光從窗戶透入，戲劇性光影，超寫實渲染，電影級構圖，東方仙俠美學，8K解析度
