### 魔網之心
| 項目 | 內容 |
|------|------|
| **等級** | 史詩階 |
| **類型** | 輔助物品 |
| **持有者** | 梅林迪斯 |
| **煉製者** | 奧術之塔 |
| **說明** | 學院贈送，可感知魔網流動，輔助施法。 |

#### 外觀說明
魔網之心呈完美的球形，直徑約三寸，以純粹的魔網能量凝結而成，通體呈現半透明的銀白色。球體內部可見無數細密的魔力絲線交織成網狀結構，如同微縮的魔網本身。當魔網感知啟動時，球體會散發出柔和的銀色光暈，光暈中浮現出周圍魔網流動的軌跡，如同空氣中的水流般清晰可見。

#### 文生圖提示詞
4K電影劇照風格，一顆半透明銀白色魔網之心懸浮於奧術之塔的修煉室中，球體內部魔力絲線交織成網狀結構，散發柔和銀色光暈，光暈中浮現魔網流動軌跡如同空中水流，背景是魔法陣與魔法典籍，塔外星光透過圓頂窗戶灑入，戲劇性光影，超寫實渲染，電影級構圖，東方仙俠美學，8K解析度

#### 物品能力
| 能力 | 說明 |
|------|------|
| **魔網感知** | 感知魔網流動，識別異種能量 |
| **施法輔助** | 輔助施法，提升施法效率 |
| **魔力儲存** | 儲存魔力，方便戰鬥中使用 |
