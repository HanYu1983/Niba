### 記錄玉簡

| 項目 | 內容 |
|------|------|
| **等級** | 黃階 ~ 玄階 |
| **類型** | 記錄法寶 |
| **持有者** | 內門弟子、長老、研究人員、交流使者 |
| **煉製者** | 器堂首座、藏經閣長老 |
| **說明** | 用於記錄靈氣波動、陣法痕跡、修煉過程的專用法寶，可捕捉並存儲能量信息，是研究與教學的重要工具。 |

#### 外觀說明
記錄玉簡長約三寸半，寬半寸，厚三分，以透明晶瑩的靈玉雕琢而成，形制簡潔流暢。玉簡表面刻滿記錄陣紋，符文排列成層次遞進的圖案，呈現出水紋般的視覺效果。玉簡頂端鑲嵌一顆豌豆大小的記錄晶石，平時呈現深藍色光澤，記錄時會發出柔和的銀白色光芒。當記錄完成後，晶石會暗淡，直至下次激活。

記錄玉簡的透明玉質內部可見細密的光絲流動，這些光絲代表著已儲存的數據，記錄越多光絲越密集。

#### 文生圖提示詞
4K電影劇照風格，一枚透明晶瑩的靈玉簡置於石桌之上，內部隱約可見銀白色的光絲交織流動，頂端的記錄晶石散發著深藍色的微光，背景是古老的藏經閣，書架上擺滿泛黃的典籍，一隻纖細的手正輕輕按在玉簡上，柔和而神秘的藍銀光芒籠罩著整個場景，戲劇性光影，超寫實渲染，東方仙俠美學，8K解析度

#### 法寶能力

| 能力 | 說明 |
|------|------|
| **靈氣記錄** | 捕捉並記錄周圍靈氣的波動、流向、密度變化 |
| **陣法痕跡記錄** | 記錄陣法的結構、靈氣節點分佈、運行方式 |
| **能量波紋捕捉** | 記錄魔法波紋、劍意波動等能量簽名 |
| **修煉過程追蹤** | 記錄使用者修煉時的靈氣流動模式與進度 |
| **環境掃描** | 掃描特定區域的靈氣濃度、異常現象 |
| **數據對比** | 可比對不同時間點的記錄，找出變化與異常 |
| **可視化呈現** | 將記錄轉化為光幻投影，直觀展示能量流動 |

#### 記錄容量

| 等級 | 容量 | 說明 |
|------|------|------|
| **黃階（入門級）** | 10 ~ 20 條記錄 | 可記錄簡單的靈氣波動，適合初入修行者 |
| **玄階（進階級）** | 50 ~ 100 條記錄 | 可記錄複雜陣法、交叉能量現象，適合研究人員 |
| **地階（高階級）** | 300 + 條記錄 | 可記錄長期修煉數據、大型陣法，適合長老級別 |

#### 記錄精度

| 精度級別 | 說明 |
|------|------|
| **粗略記錄** | 只記錄能量波動的基本特徵，文件小，消耗少 |
| **標準記錄** | 記錄完整的能量流動軌跡和特性參數 |
| **詳細記錄** | 記錄微觀層面的靈氣變化，文件大，消耗多 |
| **高精度記錄** | 記錄能量的細微波動，包括隱性信息，消耗大 |

#### 獲取方式
- **贈予**：藏經閣長老或指導長老配備
- **貢獻點兌換**：300 ~ 800 貢獻點（依等級）
- **任務獎勵**：完成研究協作任務贈送
- **自我煉製**：器堂弟子可自行研製（需材料與引導）

#### 使用限制

| 限制 | 說明 |
|------|------|
| **靈力消耗** | 每條記錄消耗少量靈力，精度越高消耗越大 |
| **記錄距離** | 記錄範圍通常為方圓百米內，遠距離記錄需靠近目標 |
| **干擾因素** | 強烈靈氣風暴、混亂的多重能量現象會降低精度 |
| **冷卻時間** | 連續高精度記錄後需冷卻片刻以恢復 |
| **境界要求** | 煉氣期可使用黃階記錄玉簡；築基期可使用玄階；金丹期可使用地階 |
| **一次性清空** | 記錄滿後需主動清空數據才能重新記錄，無法增量擴容 |

#### 特殊用途

| 用途 | 說明 |
|------|------|
| **教學輔助** | 長老可記錄標準修煉模式，展示給弟子學習 |
| **陣法研究** | 研究人員用於記錄陣法運行過程，分析其原理 |
| **異常調查** | 記錄異常靈氣現象的痕跡，作為調查證據 |
| **修煉對比** | 同一修行者在不同時期的修煉數據對比，評估進度 |
| **東西方法術對比研究** | 交流使者用於記錄靈氣與魔力的差異特性 |
| **靈魔融合實驗** | 研究靈氣與魔力融合時的能量變化過程 |

#### 讀取方式
- **直接觀看**：按壓晶石投射光幻影像
- **與傳訊玉簡配合**：將記錄發送給遠方的接收者
- **藏經閣分析**：由專業人員在藏經閣使用專用設備進行深度分析
- **多重對比**：多枚記錄玉簡同時對比，發現規律

#### 維護說明
- 記錄玉簡表面應定期用清水擦拭，避免靈塵積累
- 長期存放時應置於陰涼乾燥處，避免受潮
- 不宜暴露於強烈陽光或靈氣風暴環境
- 晶石若出現裂紋應立即送往器堂修復，否則可能導致數據損毀

#### 常見應用場景
- 蜀山藏經閣的陣法研究
- 艾琳娜記錄陰煞之氣的異常痕跡（章節6）
- 趙無極研究靈魔陣法的融合過程
- 長老級別進行弟子修煉進度評估
