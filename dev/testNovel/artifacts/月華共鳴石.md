### 月華共鳴石
| 項目 | 內容 |
|------|------|
| **等級** | 特殊（天階） |
| **類型** | 共鳴法寶 |
| **持有者** | 李雲鋒、蘇清月 |
| **煉製者** | 李雲鋒、蘇清月 |
| **說明** | 李雲鋒與蘇清月共同煉製，可產生月華共鳴。 |

#### 外觀說明
月華共鳴石由兩塊半月形的寶石組成，每塊直徑約兩寸，以雲魔鐵與月華鐵融合打造而成。左半塊呈現深邃的暗藍色澤，代表李雲鋒的雲魔之力；右半塊呈現銀白色澤，代表蘇清月的月華之力。兩塊寶石靠近時會自動產生共鳴，散發出璀璨的藍白色光芒，光芒中浮現出雙劍合璧的影像，靈魔能量在兩石之間形成美麗的光橋。

#### 文生圖提示詞
4K電影劇照風格，兩塊半月形月華共鳴石靜置於月光下的石台上，左半塊暗藍色右半塊銀白色，兩石靠近產生共鳴散發璀璨藍白色光芒，光芒中浮現雙劍合璧影像，靈魔能量在兩石之間形成美麗光橋，背景是月光灑落的修煉室，窗外明月高懸，戲劇性光影，超寫實渲染，電影級構圖，東方仙俠美學，8K解析度

| 能力 | 說明 |
|------|------|
| **劍氣共鳴** | 兩人劍氣產生共鳴，威力倍增 |
| **魔力共鳴** | 兩人魔力產生共鳴，治癒效果提升 |
| **雙劍合璧** | 雙劍合璧，威力無窮 |
| **靈魔合一** | 靈魔合一，超脫凡塵 |

#### 獲取方式
- **本命煉製**：李雲鋒、蘇清月共同煉製，他人無法使用
