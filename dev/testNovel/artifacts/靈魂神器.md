### 靈魂神器
| 項目 | 內容 |
|------|------|
| **等級** | 傳說階 |
| **類型** | 治癒物品 |
| **持有者** | 院長 |
| **煉製者** | 艾爾德里克 |
| **說明** | 傳說神器，可復活死亡靈魂，修復致命損傷。 |

#### 外觀說明
靈魂神器呈完美的球形，直徑約五寸，以傳說中的靈魂本源礦石打造而成，通體呈現深邃的白金色澤，內部可見無數靈魂碎片如星塵般緩緩旋轉。神器表面刻滿了靈魂復活與天命重鑄的古老符文，符文以七彩靈漆填充，散發著神聖而神秘的光芒。當靈魂復活啟動時，神器會爆發出璀璨的七彩光芒，光芒中浮現出完整的靈魂影像，如同創世般重新凝聚。

#### 文生圖提示詞
4K電影劇照風格，一顆白金色靈魂神器懸浮於院長密室中央，內部靈魂碎片如星塵般旋轉，表面七彩靈魂復活符文閃爍，爆發璀璨七彩光芒，光芒中浮現完整靈魂影像如同創世凝聚，背景是莊嚴的院長密室，燭光與神器光芒交相輝映，戲劇性光影，超寫實渲染，電影級構圖，東方仙俠美學，8K解析度

#### 物品能力
| 能力 | 說明 |
|------|------|
| **靈魂復活** | 復活死亡靈魂 |
| **致命修復** | 修復致命靈魂損傷 |
| **輪迴修復** | 修復中斷的輪迴印記 |
| **天命重鑄** | 重鑄消失的天命印記 |

#### 獲取方式
- **院長傳承**：只有院長可繼承
- **緊急情況**：靈魂致命損傷時可使用
