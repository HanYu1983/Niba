### 靈魂水晶
| 項目 | 內容 |
|------|------|
| **等級** | 精煉階 |
| **類型** | 治癒物品 |
| **持有者** | 正式法師以上 |
| **煉製者** | 煉金系導師 |
| **說明** | 儲存靈魂能量的水晶，可輔助靈魂恢復。 |

#### 外觀說明
靈魂水晶呈完美的六面柱體，高約四寸，以純粹的靈魂能量凝結而成，通體呈現透明的淡紫色。水晶內部可見絲絲縷縷的靈魂能量如霧氣般緩緩流動，形成美麗的光影效果。當靈魂修復啟動時，水晶會散發出柔和的紫色光暈，光暈中夾雜著金色的靈魂能量絲線，如同晨曦中的薄霧，緩緩包裹使用者的靈魂。

#### 文生圖提示詞
4K電影劇照風格，一根淡紫色透明靈魂水晶靜置於煉金系的展示台上，水晶內部靈魂能量如霧氣般緩緩流動，散發柔和紫色光暈，光暈中夾雜金色靈魂能量絲線，背景是擺滿煉金器材的實驗室，燭光與水晶光芒交相輝映，戲劇性光影，超寫實渲染，電影級構圖，東方仙俠美學，8K解析度

#### 物品能力
| 能力 | 說明 |
|------|------|
| **靈魂儲存** | 儲存靈魂能量，方便使用 |
| **靈魂修復** | 修復輕度靈魂損傷 |
| **能量補充** | 補充流失的靈魂能量 |

- **貢獻點兌換**：1500 貢獻點
- **煉金系製作**：煉金系弟子煉製
