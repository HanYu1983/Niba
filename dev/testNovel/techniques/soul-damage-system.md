# 神魂損傷 — Soul Damage

## 神魂損傷概覽

### 基本資訊
| 項目 | 內容 |
|------|------|
| **名稱** | 神魂損傷（Soul Damage） |
| **別稱** | 靈魂創傷、神識損毀、魂裂 |
| **本質** | 修煉者神魂（靈魂本源）受到的損傷 |
| **嚴重程度** | 輕度→中度→重度→魂飛魄散 |

## 一、神魂本質

### 1.1 神魂定義

#### 東方仙俠體系
在東方仙俠體系中，神魂是修煉者的靈魂本源，是意識、記憶、情感的載體。隨著修煉境界提升，神魂會逐漸強化：

| 境界 | 神魂狀態 | 說明 |
|------|---------|------|
| **煉氣期** | 魂體初成 | 神魂初步凝聚，脆弱易損 |
| **築基期** | 魂體固化 | 神魂逐漸穩固，抗性提升 |
| **金丹期** | 魂丹合一 | 神魂與金丹融合，不易受損 |
| **元嬰期** | 元嬰出竅 | 神魂化為元嬰，可脫離肉身 |
| **化神期** | 神魂化形 | 神魂可具現化，觸及法則 |
| **煉虛期** | 虛空魂體 | 神魂可穿梭虛空，不朽不滅 |
| **合體期** | 神魂合一 | 神魂與天地合一，超脫凡塵 |
| **大乘期** | 神魂飛升 | 神魂超脫輪迴，準備飛升 |

#### 西方魔法體系
在西方魔法體系中，對應概念為「靈魂本源」（Soul Essence）或「意識核心」（Consciousness Core）：

| 階級 | 靈魂狀態 | 說明 |
|------|---------|------|
| **學徒階** | 靈魂感知 | 初步感知靈魂存在 |
| **見習法師** | 靈魂固化 | 靈魂逐漸穩固 |
| **正式法師** | 靈魂核心 | 靈魂形成核心，不易受損 |
| **魔導師** | 靈魂領域 | 靈魂可展開領域，影響他人 |
| **大魔導師** | 靈魂法則 | 靈魂觸及法則，改變現實 |
| **聖域** | 靈魂不朽 | 靈魂不朽不滅，可重生 |
| **半神** | 靈魂神化 | 靈魂接近神明，超脫凡塵 |
| **神選者** | 靈魂飛升 | 靈魂超脫輪迴，準備飛升 |

### 1.2 神魂結構

```
神魂（Soul）
    ├── 意識層（Consciousness）
    │     ├── 記憶（Memory）
    │     ├── 情感（Emotion）
    │     └── 意志（Will）
    │
    ├── 能量層（Energy）
    │     ├── 魂力（Soul Power）
    │     ├── 靈覺（Spiritual Sense）
    │     └── 感知（Perception）
    │
    └── 本源層（Origin）
          ├── 靈魂印記（Soul Mark）
          ├── 輪迴印記（Reincarnation Mark）
          └── 天命印記（Destiny Mark）
```

## 二、神魂損傷類型

### 2.1 按損傷程度分類

| 類型 | 說明 | 症狀 | 治癒難度 |
|------|------|------|---------|
| **輕度損傷** | 神魂表面受損，未傷及本源 | 頭痛、記憶模糊、靈覺減弱 | ★★（可自愈） |
| **中度損傷** | 神魂內部受損，影響意識層 | 記憶缺失、情感紊亂、意志動搖 | ★★★（需藥物輔助） |
| **重度損傷** | 神魂本源受損，影響能量層 | 魂力流失、靈覺喪失、意識模糊 | ★★★★（需特殊功法） |
| **致命損傷** | 神魂本源破碎，影響本源層 | 魂飛魄散、意識消失、輪迴中斷 | ★★★★★（幾乎不可逆） |

### 2.2 按損傷原因分類

#### 暗影魔力腐蝕
| 項目 | 內容 |
|------|------|
| **原因** | 暗影魔力侵入神魂，腐蝕靈魂本源 |
| **症狀** | 神魂變黑、意志被操控、情感扭曲 |
| **後果** | 神魂墮落，成為暗影傀儡 |
| **治癒方法** | 靈魔治癒術、劍意淨化、神聖魔法 |

#### 功法反噬
| 項目 | 內容 |
|------|------|
| **原因** | 修煉功法不當，導致神魂反噬 |
| **症狀** | 魂力逆流、意識混亂、記憶錯亂 |
| **後果** | 修為盡失，神魂受損 |
| **治癒方法** | 停止修煉、調息養魂、丹藥輔助 |

#### 戰鬥創傷
| 項目 | 內容 |
|------|------|
| **原因** | 戰鬥中神魂受到直接攻擊 |
| **症狀** | 神魂震盪、意識模糊、靈覺減弱 |
| **後果** | 神魂受損，戰力下降 |
| **治癒方法** | 休養恢復、丹藥輔助、治癒功法 |

#### 心魔入侵
| 項目 | 內容 |
|------|------|
| **原因** | 心魔侵入神魂，操控意識 |
| **症狀** | 意志動搖、情感扭曲、記憶混亂 |
| **後果** | 神魂墮落，走火入魔 |
| **治癒方法** | 劍心通明訣、心境修煉、外力輔助 |

#### 天劫損傷
| 項目 | 內容 |
|------|------|
| **原因** | 渡劫時天劫攻擊神魂 |
| **症狀** | 神魂震盪、魂力流失、意識模糊 |
| **後果** | 渡劫失敗，神魂受損或魂飛魄散 |
| **治癒方法** | 渡劫法寶、外力護法、丹藥輔助 |

#### 壽元耗盡
| 項目 | 內容 |
|------|------|
| **原因** | 壽元耗盡，神魂自然衰敗 |
| **症狀** | 神魂衰弱、意識模糊、記憶流失 |
| **後果** | 神魂消散，輪迴轉生 |
| **治癒方法** | 延壽丹藥、突破境界、轉世重修 |
