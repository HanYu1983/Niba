# 外貌年齡設定 — Appearance Aging System

## 概述

在靈源紀元中，修煉者的外貌年齡遵循「自然衰老 + 突破返老還童」的機制。修煉者本身會像凡人一樣自然衰老，但每次境界突破時，由於壽命大幅增加、生命本源強化，會產生「返老還童」現象，使外貌變得較年輕。

---

## 一、外貌衰老與返老還童機制

### 1.1 自然衰老機制

| 狀態 | 說明 |
|------|------|
| **凡人** | 60~80 歲自然衰老死亡，外貌隨年齡自然變化 |
| **未突破修煉者** | 即使開始修煉，若未突破境界，外貌仍會隨年齡自然衰老 |
| **突破後** | 每次境界突破，壽命大幅增加，外貌會變得較年輕 |

### 1.2 突破返老還童機制

| 境界突破 | 壽命上限 | 外貌返老還童幅度 | 說明 |
|---------|---------|----------------|------|
| **煉氣期** | 100~150 歲 | 外貌顯著年輕化 | 初步淬鍊肉身，修者的容顏變得更加青春 |
| **築基期** | 200~300 歲 | 外貌進一步年輕化 | 靈力固化，修者變得更年輕、更有精神 |
| **金丹期** | 500~800 歲 | 外貌顯著恢復年輕 | 凝丹成核，修者容顏比之前更加年輕但不會回到初始年紀 |
| **元嬰期** | 1000~2000 歲 | 外貌變得更為超凡年輕 | 元嬰出竅，修者的容顏呈現成熟而不老的狀態 |
| **化神期** | 3000~5000 歲 | 外貌更接近返璞歸真 | 神魂化形，修者的外貌看起來沉穩而有道韻 |
| **煉虛期** | 8000~10000 歲 | 外貌接近不朽 | 虛空煉體，修者容顏穩定且不顯衰老 |
| **合體期** | 15000~20000 歲 | 外貌呈現歷練感 | 肉身與天地合一，容顏可能呈現百歲以上的長者風範 |
| **大乘期** | 超脫凡塵 | 外貌可自由控制 | 超脫輪迴，不受外貌限制 |

### 1.3 返老還童機制說明

| 機制 | 說明 |
|------|------|
| **壽命驅動** | 每次突破壽命大幅增加，生命本源強化，驅動外貌返老還童 |
| **自然衰老持續** | 返老還童後，外貌仍會隨時間自然衰老，直到下次突破 |
| **氣質變化** | 雖然外貌年輕化，但氣質會隨境界提升而更加成熟超凡 |
| **能量光澤** | 高境界修煉者的能量會使外貌散發特殊光澤，增添氣質 |

## 三、外貌年齡計算

### 3.1 計算公式

```
當前外貌年齡 = 突破時的外貌年齡 + 突破後經過的年數 × 衰老係數
```

| 因素 | 說明 |
|------|------|
| **突破時外貌年齡** | 變年輕後的參考外貌年齡 |
| **突破後經過年數** | 從突破到現在經過的實際年數 |
| **衰老係數** | 修煉者越高，衰老速度越慢（約為凡人的 1/10~1/50） |

### 3.2 計算範例

#### 範例一：張無涯（金丹期）
| 項目 | 數值 | 說明 |
|------|------|------|
| **生卒年** | OE 24750 — 在世 | 蜀山修煉世家 |
| **突破金丹期年份** | OE 24850 | 100 歲時突破 |
| **突破時外貌年齡** | 55 歲 | 作為突破後的參考外貌年齡 |
| **突破後經過年數** | 依故事時間而定 | 從突破到當前故事時間 |
| **衰老係數** | 1/50 | 金丹期衰老速度 |
| **外貌年齡** | **55 + 經過年數 × 1/50** | 隨故事推進計算 |

## 四、特殊情況

### 4.1 外貌可自由控制

| 境界 | 說明 | 代表角色 |
|------|------|---------|
| **大乘期** | 外貌可自由控制，可呈現任何年齡 | 凌霄劍尊（已飛升） |
| **化神期以上** | 外貌可部分控制，可選擇返老還童幅度 | 雲霄劍尊（掌門） |

### 4.2 外貌異常情況

| 情況 | 說明 | 影響 |
|------|------|------|
| **走火入魔** | 境界突破失敗，外貌可能提前衰老或扭曲 | 外貌呈現異常狀態 |
| **神魂損傷** | 神魂受損，外貌可能提前衰老 | 氣質渙散，外貌不穩定 |
| **外力干涉** | 被他人法寶或魔法干涉外貌 | 外貌可能暫時改變 |
| **丹藥/法寶輔助** | 使用延壽或淬鍊類丹藥法寶 | 外貌可能比正常更年輕 |

### 5.2 外貌設定注意事項

1. **自然衰老**：修煉者本身會像凡人一樣自然衰老，不會定格
2. **突破返老還童**：每次境界突破，外貌會變得較年輕
3. **氣質隨境界變化**：雖然外貌年輕化，但氣質會隨境界提升而更加成熟超凡
4. **衰老速度減緩**：境界越高，衰老速度越慢（約為凡人的 1/10~1/100）
5. **丹藥輔助**：使用延壽或淬鍊類丹藥法寶，可使外貌比正常更年輕
6. **自由控制例外**：大乘期以上修煉者可自由控制外貌
