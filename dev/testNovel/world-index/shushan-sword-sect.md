# 蜀山劍派 — 宗門設定文檔

## 一、宗門概覽

### 1.1 基本資訊
| 項目 | 內容 |
|------|------|
| **宗門名稱** | 蜀山劍派（Shushan Sword Sect） |
| **別稱** | 劍修聖地、蜀山、劍宗 |
| **創立時間** | 靈源紀元 OE 10000 年左右 |
| **創派祖師** | 凌霄劍尊（待補充詳細設定） |

- **象徵物**：劍池、古松、雲海

## 二、歷史淵源

### 2.1 創派傳說
相傳靈源紀元 OE 10000 年左右，凌霄劍尊於岷山之巔觀天地靈氣流動，忽有所悟，以劍指天，引動靈脈之氣，斬開雲霧，見天地法則一線。遂於此地建立蜀山劍派，以劍入道，開創劍修一脉。

### 2.2 重大歷史事件

| 紀年 | 事件 | 說明 |
|------|------|------|
| OE 10000 | 創派 | 凌霄劍尊建立蜀山劍派 |
| OE 12000 | 劍池開鑿 | 於靈脈節點開鑿蜀山劍池，成為修煉聖地 |
| OE 15000 | 第一次靈魔戰爭 | 蜀山派出三千劍修支援正道，斬殺魔族大將 |
| OE 15500 | 靈魔和約 | 蜀山派代表出席和約簽訂，主張和平 |
| OE 20000 | 大災變 | 創世遺跡爆發，蜀山啟動護山大陣，保全宗門 |

### 2.4 新紀元事件詳解：東西方法術交流

#### 事件背景
大災變（OE 20000）後五百年，世界逐漸恢復穩定。蜀山劍派在修復護山大陣的過程中，發現傳統劍陣對某些異種能量（暗影魔力、空間裂縫）效果有限。與此同時，西方艾爾德里亞大陸的魔法議會也面臨類似困境——純魔法攻擊對東方妖族的肉身防禦效果不佳。

在此背景下，蜀山第六代掌門「雲霄劍尊」與魔法議會大魔導師「梅林迪斯」於靈魔交界碑會面，簽訂《靈魔交流協議》，開啟東西方法術交流的新紀元。

#### 交流內容
| 項目 | 東方輸出 | 西方輸出 |
|------|---------|---------|
| **功法** | 劍心通明訣、基礎劍陣 | 元素魔法基礎、魔力感知法 |
| **技術** | 煉器術、符籙製作 | 煉金術、魔法陣繪製 |
| **理念** | 以劍入道、領悟劍意 | 魔法理論、咒語結構 |
| **人才** | 派遣劍修弟子 | 派遣魔法學徒 |

#### 首批交流使者
| 姓名 | 身份 | 境界 | 目的地 | 學習內容 |
|------|------|------|-------|---------|
| **李雲鋒** | 真傳弟子 | 金丹期 | 奧術之塔 | 魔劍術、元素附魔 |
| **蘇清月** | 內門弟子 | 築基期 | 精靈森林 | 自然魔法、劍術融合 |
| **趙無極** | 陣堂弟子 | 築基期 | 中央王國 | 魔法陣與劍陣對比研究 |
| **艾琳娜** | 魔法學徒 | 見習法師 | 蜀山劍派 | 劍修基礎、靈氣感知 |

#### 魔劍術定義
魔劍術（Spellblade Arts）是東西方法術融合的產物，結合了：
- **東方劍修**：劍意、御劍術、劍氣
- **西方魔法**：元素附魔、魔力強化、咒語瞬發

**核心特點**：
1. 以劍為媒介，施展魔法效果
2. 劍氣與魔法能量可互相轉化
3. 戰鬥方式更靈活，可遠可近
4. 修煉難度極高，需同時掌握兩種體系

#### 事件影響
| 面向 | 影響 |
|------|------|
| **宗門發展** | 新增「魔劍堂」，專門研究魔劍術 |
| **功法創新** | 開發《靈魔劍典》，融合東西方法術 |
| **勢力關係** | 與奧術之塔建立長期合作關係 |
| **爭議** | 保守派認為偏離劍道正統，引發內部爭論 |
| **人才培養** | 培養出首批「雙修」劍修，戰力大幅提升 |

#### 後續發展
- OE 25500：首批交流弟子歸宗，帶回魔劍術基礎
- OE 26000：魔劍堂正式成立，由李雲鋒擔任首任堂主
- OE 27000：《靈魔劍典》編纂完成，列為宗門選修功法
- OE 28000：蜀山劍派與奧術之塔聯合舉辦「靈魔劍術大賽」
- OE 30000：魔劍術成為蜀山特色之一，但仍非主流

#### 創作提示
此事件可作為：
1. **主角機緣**：主角意外獲得魔劍術傳承，成為雙修天才
2. **宗門衝突**：保守派與革新派的權力鬥爭
3. **跨界劇情**：主角被選為交流使者，前往西方大陸
4. **功法創新**：主角融合東西方法術，開創全新劍道
5. **陰謀線索**：交流背後隱藏著更大的陰謀（如魔教滲透）

## 六、宗門規矩

### 6.1 門規要點
1. **劍心為本**：弟子需以劍心為本，不可偏離劍道，違者廢除修為
2. **尊師重道**：不得背叛師門，違者逐出宗門，追殺到底
3. **除魔衛道**：定期參與宗門任務，斬妖除魔，維護正道
4. **同門互助**：不得同門相殘，違者受刑堂處置
5. **劍陣保密**：蜀山劍陣為鎮派之寶，非掌門許可不得外傳
6. **劍冢禁入**：非掌門或長老許可，不得進入劍冢
7. **貢獻制度**：所有資源按貢獻點分配，多勞多得

### 6.2 懲罰制度
| 罪行 | 懲罰 |
|------|------|
| 輕微違規 | 罰抄劍譜、禁閉 |
| 同門爭鬥 | 刑堂審判，扣除貢獻點 |
| 背叛師門 | 廢除修為，逐出宗門，追殺 |
| 洩露機密 | 視情節輕重，最重死刑 |
| 勾結魔道 | 死刑，魂飛魄散 |

## 十二、外觀設定

### 12.1 整體外觀
蜀山劍派坐落於岷山山脈之巔，九座山峰環繞主峰凌霄峰，形成一個天然的九宮八卦陣勢。整個宗門被雲海環繞，宛如仙境般懸浮於天地之間。主峰凌霄峰高聳入雲，峰頂建有宏偉的宮殿群，遠遠望去仿佛九柄巨劍直指蒼穹。宗門建築多為青石白玉構築，雕樑畫棟，充滿仙俠氣息。

### 12.2 山峰特徵
- **材質**：主要建築使用青石和白玉，象徵劍意純淨。山間古松參天，枝葉茂密，根部盤踞岩石，歷經千年風雨。
- **顏色**：基調為青白色，青色代表劍意，白玉建築在陽光下閃耀著聖潔的光芒。雲海時而青白相間，時而金光萬道。
- **結構**：九峰各有分工，主峰凌霄峰為核心，其他八峰環繞，形成防禦與修煉的完美佈局。每峰之間有飛橋相連，橋下雲霧繚繞。

### 12.3 劍池象徵
蜀山劍池位於劍池峰頂，這是一個巨大的圓形池塘，直徑約五十米，池水清澈見底，內蘊無數劍意。池邊立有九柄鎮池古劍，劍身沒入池水，劍氣縱橫，形成一道道可見的劍芒。白天，劍池會反射陽光，形成七彩劍虹；夜晚，池水會散發淡淡的青色光芒，照亮整個劍池峰。

### 12.4 靈脈融合
整個蜀山被強大的靈脈環繞，靈氣如雲霧般在山間流動，形成天然的修煉環境。山間偶爾會出現靈氣漩渦，吸引飛鳥靈獸。當弟子修煉時，靈脈會輕微脈動，增幅劍意的威力。

### 12.5 防禦設施
蜀山護山大陣「兩儀微塵陣」覆蓋整個宗門，這是一個無形的能量屏障，呈現出淡淡的青色光暈。陣法能自動抵禦外敵，並在受到威脅時自動強化。陣法的邊緣偶爾會閃現出劍氣般的青色閃電，顯示其鋒銳的防禦力。

### 12.6 周圍環境
蜀山周圍是廣袤的岷山山脈，山間雲海茫茫，飛鳥難渡。宗門入口處有一道天然的雲梯，蜿蜒而上，直通山門。山腳下有蜀山鎮，為凡人聚集之地，供應宗門所需物資。山間遍佈靈草仙葯，野獸靈禽出沒。

### 12.7 仙俠效果
- **雲海變化**：蜀山的雲海會隨靈氣波動而變化，晴天時雲淡風輕，修煉時雲氣凝聚成劍形。
- **劍氣縱橫**：山間偶爾會出現可見的劍氣，劃破長空，仿佛無數隱形劍客在比試。
- **靈禽仙獸**：山中棲息著各種靈禽仙獸，如青鸞、白鶴、靈猿等，增添仙境氣息。

### 12.8 象徵意義
蜀山劍派不僅是修仙宗門，更是劍道文明的象徵。九峰環繞代表九天之劍，雲海環繞象徵超凡脫俗；青白色彩體現劍心的純淨與鋒銳；劍池則是劍修修行的核心，蘊含無盡劍意。
