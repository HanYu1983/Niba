# 氣與瑪那 — Qi & Mana

## 一、能量本質

### 1.1 靈源統一理論
| 項目 | 氣（Qi） | 瑪那（Mana） | 統一理論 |
|------|---------|-------------|---------|
| **本質** | 靈源的東方表現形式 | 靈源的西方表現形式 | 同為靈源分化能量 |
| **起源** | 盤古身化萬物，靈源散於天地 | 創世神艾琉恩以原初之言塑造世界 | 同一創世事件的不同描述 |
| **屬性** | 陰陽五行，流動變化 | 元素派系，結構穩定 | 能量表現形式不同，本質相同 |
| **感知** | 靈覺、靈根 | 奧術感知、魔法天賦 | 同一感知能力的不同稱呼 |

### 1.2 能量特性對比

#### 氣（Qi）的特性
| 特性 | 說明 |
|------|------|
| **流動性** | 如水流般在靈脈與經脈中流動，變化莫測 |
| **陰陽平衡** | 具有陰陽兩種屬性，需保持平衡 |
| **五行相生相剋** | 金、木、水、火、土五行循環 |
| **內斂性** | 傾向於內斂、凝聚、淬鍊自身 |
| **境界壁壘** | 修煉需突破境界壁壘，每次突破都是質變 |
| **壽元關聯** | 境界越高，壽元越長 |

#### 瑪那（Mana）的特性
| 特性 | 說明 |
|------|------|
| **結構性** | 如網格般在魔網中分布，結構穩定 |
| **元素親和** | 與火、水、風、土等元素產生共鳴 |
| **咒語引導** | 需通過咒語、手勢、材料引導 |
| **外放性** | 傾向於外放、操控、改變外界 |
| **階級累積** | 魔法階級通過知識累積與實踐提升 |
| **壽命獨立** | 魔法階級與壽命無直接關聯 |

## 三、感知與吸收

### 3.1 氣的感知與吸收

#### 靈根系統
| 靈根類型 | 感知能力 | 吸收效率 | 占比 |
|---------|---------|---------|------|
| **天靈根** | 直接感知靈氣流動 | 極高 | 萬中無一 |
| **異靈根** | 感知特定屬性靈氣 | 高（特定屬性） | 千中取一 |
| **雜靈根** | 感知多種屬性靈氣 | 中等 | 十中取一 |
| **無靈根** | 無法感知靈氣 | 極低 | 普通人 |

#### 吸收方式
1. **引氣入體**：通過呼吸、冥想引導靈氣進入體內
2. **經脈運轉**：靈氣沿經脈運轉，淬鍊肉身
3. **丹田儲存**：靈氣匯聚於丹田，形成靈力核心
4. **境界突破**：靈力累積到一定程度，突破境界壁壘

#### 修煉風險
| 風險 | 說明 | 後果 |
|------|------|------|
| **走火入魔** | 靈氣運轉失控 | 經脈受損，境界跌落 |
| **靈氣反噬** | 吸收過多靈氣 | 肉身崩潰 |
| **心魔入侵** | 心境不穩 | 神魂受損 |
| **靈脈枯竭** | 過度抽取靈脈 | 區域靈氣失衡 |

## 四、氣與瑪那的轉換

### 4.1 轉換理論基礎

#### 萬法同源理論
由梅林迪斯於 OE 24500 年提出，核心觀點：
1. **能量同源**：氣與瑪那本質相同，只是表現形式不同
2. **轉換可能**：通過特定方法，氣可轉換為瑪那，反之亦然
3. **融合創新**：轉換後可開創全新法術體系

#### 轉換原理
```
氣（Qi） → 陰陽五行轉化 → 瑪那（Mana）
    ↓                        ↓
靈脈網絡 ← 靈魔共鳴 ← 魔網系統
```

### 4.2 轉換方法

#### 氣轉瑪那
| 方法 | 說明 | 效率 | 風險 |
|------|------|------|------|
| **靈魔轉換訣** | 通過特定功法將靈氣轉換為魔力 | 中等 | 靈氣流失 |
| **劍魔融合** | 劍氣與魔力融合，形成魔劍氣 | 高 | 劍心受損 |
| **靈魔陣法** | 通過陣法轉換靈氣為魔力 | 高 | 陣法失靈 |

#### 瑪那轉氣
| 方法 | 說明 | 效率 | 風險 |
|------|------|------|------|
| **魔力煉氣訣** | 通過特定功法將魔力轉換為靈氣 | 中等 | 魔力反噬 |
| **魔劍逆轉** | 魔劍氣逆轉為劍氣 | 高 | 魔法迴路受損 |
| **魔靈陣法** | 通過陣法轉換魔力為靈氣 | 高 | 陣法失靈 |

### 4.3 轉換應用

#### 魔劍術（Spellblade Arts）
