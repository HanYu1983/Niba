## 二、歷史淵源

### 2.1 創院傳說
相傳靈源紀元 OE 10000 年左右，大奧術師艾爾德里克於中央王國首都感知到魔網最強節點。他以原初之言詠唱七天七夜，引動魔網之力，從地面升起一座高塔。此塔直達雲霄，成為魔法研究的聖地，奧術之塔由此誕生。

## 六、學院規矩

### 6.1 院規要點
1. **知識為本**：法師需追求真理，不可停止學習，違者剝奪法師資格
2. **尊師重道**：不得背叛學院，違者逐出學院，列入黑名單
3. **魔法研究**：定期參與學院任務，探索新魔法，推動魔法發展
4. **同窗互助**：不得同窗相殘，違者受議會審判
5. **禁書保密**：禁書區典籍為學院機密，非院長許可不得外傳
6. **禁區禁入**：非院長或議會許可，不得進入禁書區
7. **貢獻制度**：所有資源按貢獻點分配，多勞多得

### 6.2 懲罰制度
| 罪行 | 懲罰 |
|------|------|
| 輕微違規 | 罰抄咒語、禁閉 |
| 同窗爭鬥 | 議會審判，扣除貢獻點 |
| 背叛學院 | 剝奪法師資格，逐出學院，追殺 |
| 洩露機密 | 視情節輕重，最重死刑 |
| 勾結暗影 | 死刑，靈魂封印 |

## 十二、外觀設定

### 12.1 整體外觀
奧術之塔是一座直插雲霄的宏偉高塔，塔身由純淨的魔法晶石構築而成，外表呈現出深邃的藍銀色澤。塔高約三百米，直徑從底部的一百米逐漸收窄至塔頂的三十米，形成一個優雅的錐形結構。塔身表面佈滿複雜的魔法符文，這些符文在魔網波動時會發出柔和的藍色光芒，整個塔身仿佛一座活著的魔法藝術品。

### 12.2 塔身特徵
- **材質**：主要由「奧術晶石」構成，這種晶石能自然吸收魔網能量，並將其轉化為防禦力。晶石表面光滑如鏡，但內部蘊含著無數微小的魔法回路。
- **顏色**：基調為深藍色，象徵魔力的深邃；銀色符文線條在塔身縱橫交錯，代表智慧與秩序。夜晚時，塔身會散發出銀藍色的光芒，照亮整個奧術城。
- **結構**：塔身分為九層，每層高度約三十米，每層之間有寬闊的平台和露台。塔頂是一個圓形的觀測台，直徑約五十米。

### 12.3 塔頂象徵
