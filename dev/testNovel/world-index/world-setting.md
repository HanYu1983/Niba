# 靈源紀元 — 世界觀設定

## 一、世界起源：靈源（The Origin）

### 1.1 核心概念
宇宙初始，混沌未分，唯有「靈源」存在。靈源是萬物能量的根源，既是東方所稱的「道」，也是西方所稱的「原初魔力」（Primordial Mana）。

靈源分化為兩種表現形式：
- **氣（Qi）**：東方稱謂，流動於天地之間，可被修煉者吸收轉化為自身力量
- **瑪那（Mana）**：西方稱謂，本質與氣相同，只是稱呼與運用方式不同

> 📖 詳細設定請參閱：[氣與瑪那專章](qi-and-mana.md)

### 1.2 創世神話
- **東方傳說**：盤古開天，身化萬物，靈源散於天地，形成靈脈
- **西方傳說**：創世神艾琉恩（Aelion）以原初之言塑造世界，魔力隨之言語流佈

**真相**：兩者描述的是同一事件。盤古與艾琉恩是同一存在的不同稱呼。靈源在創世時分裂為「靈脈」（東方）與「魔網」（西方），實為同一能量網絡的兩種表現。

## 二、力量體系

### 2.1 東方仙俠體系：修煉之道

#### 靈根系統
| 靈根類型 | 屬性 | 說明 |
|---------|------|------|
| 天靈根 | 單一純淨 | 萬中無一，修煉速度極快 |
| 異靈根 | 變異屬性 | 如雷、風、冰等，威力特殊 |
| 雜靈根 | 多屬性混合 | 修煉緩慢，但潛力深厚 |
| 無靈根 | 無法感知靈氣 | 需靠體修或外物 |

#### 修煉境界
| 境界 | 說明 | 對應西方 |
|------|------|---------|
| 煉氣期 | 引氣入體，淬鍊肉身 | 學徒階（Apprentice） |
| 築基期 | 築造道基，靈力固化 | 見習法師（Novice Mage） |
| 金丹期 | 凝丹成核，壽元大增 | 正式法師（Full Mage） |
| 元嬰期 | 元嬰出竅，神魂不滅 | 魔導師（Archmage） |
| 化神期 | 神魂化形，觸及法則 | 大魔導師（Grand Archmage） |
| 煉虛期 | 虛空煉體，空間掌控 | 聖域（Sanctuary） |
| 合體期 | 肉身與天地合一 | 半神（Demigod） |
| 大乘期 | 渡劫飛升，超脫凡塵 | 神選者（Chosen） |

#### 修煉方式
- **功法**：吸收天地靈氣，經經脈運轉，淬鍊自身
- **丹藥**：以靈草煉丹，輔助修煉或治療
- **符籙**：以靈力書寫符文，召喚法術效果
- **法寶**：蘊含靈力的器物，可攻可守
- **陣法**：以靈力佈局，形成特殊領域

### 2.2 西方魔法體系：奧術之道

#### 魔法天賦系統
| 天賦類型 | 說明 | 對應東方 |
|---------|------|---------|
| 元素親和 | 與特定元素共鳴 | 靈根屬性 |
| 奧術感知 | 感知魔網流動 | 靈覺 |
| 血脈傳承 | 祖先魔力遺傳 | 血脈之力 |
| 神賜天賦 | 神明賜予的力量 | 天命 |

##### 元素親和詳細說明

**定義**：元素親和是修煉者與特定元素之間的天生共鳴能力，表現為對該元素魔法的敏感度與操控效率。在西方魔法體系中被視為魔法天賦的核心指標，在東方修煉體系中對應「靈根屬性」。

**親和等級**：
| 等級 | 說明 | 代表人物 |
|------|------|---------|
| 頂級 | 與元素高度共鳴，施法效率極高，可觸及法則層面 | 梅林迪斯（全屬性） |
| 高級 | 對特定元素有強烈親和，修煉速度遠超常人 | 蘇清月（冰、水） |
| 中級 | 能正常使用該元素魔法，需刻苦修煉提升 | 艾琳娜（水、風） |
| 基礎 | 僅能勉強操控，進步緩慢 | 普通學徒 |

**常見親和屬性**：
| 屬性 | 特點 | 對應靈根 |
|------|------|---------|
| 火 | 攻擊性強，爆發力高 | 火靈根 |
| 水 | 防禦與治療兼備，柔韌持久 | 水靈根 |
| 風 | 速度與靈活性，擅長輔助 | 風靈根 |
| 土 | 穩定與防禦，擅長陣法 | 土靈根 |
| 雷 | 極致攻擊，速度與破壞力並存 | 雷靈根 |
| 冰 | 控制與封印，寒氣侵蝕 | 冰靈根 |

**東西對比**：
- **西方觀點**：元素親和是天賦，決定魔法師的發展方向與上限
- **東方觀點**：靈根屬性是修煉基礎，但可通過後天努力彌補不足
- **統一理論**：兩者本質相同，都是修煉者對靈源不同表現形式的敏感度差異

**融合應用**：
- 跨體系修煉者可將元素親和與靈根屬性結合，提升修煉效率
- 艾琳娜案例：水風親和 + 靈氣感知 = 獨特的靈魔融合劍術基礎

#### 魔法階級
| 階級 | 說明 | 對應東方 |
|------|------|---------|
| 學徒階 | 學習基礎咒語 | 煉氣期 |
| 見習法師 | 掌握單一系別 | 築基期 |
| 正式法師 | 獨立施法，研究魔法 | 金丹期 |
| 魔導師 | 開創魔法，影響一方 | 元嬰期 |
| 大魔導師 | 觸及法則，改變現實 | 化神期 |
| 聖域 | 領域展開，空間掌控 | 煉虛期 |
| 半神 | 接近神明，不朽之軀 | 合體期 |
| 神選者 | 神明代行者，超脫凡塵 | 大乘期 |

#### 魔法派系
- **元素魔法**：火、水、風、土、雷、冰
- **奧術魔法**：空間、時間、重力、能量操控
- **神聖魔法**：治療、祝福、驅邪
- **暗影魔法**：詛咒、幻術、靈魂操控
- **自然魔法**：植物操控、野獸溝通、大地之力
- **煉金術**：物質轉化、藥劑製作、魔法物品

> ⚠️ 注意：暗影魔法與暗影魔力不同。暗影魔法是魔法派系之一，可控；暗影魔力是靈源的負面表現，具腐蝕性。詳見：[暗影魔力體系](../techniques/shadow-mana-system.md)

### 2.3 體系對照與統一理論

#### 能量本質
```
靈源（The Origin）
    ├── 氣（Qi）→ 東方修煉體系
    │     ├── 靈脈網絡
    │     ├── 經脈系統
    │     └── 丹田儲存
    │
    └── 瑪那（Mana）→ 西方魔法體系
          ├── 魔網（The Weave）
          ├── 魔法迴路
          └── 魔晶儲存
```

#### 核心差異
| 面向 | 東方仙俠 | 西方魔法 |
|------|---------|---------|
| 能量來源 | 天地靈氣 | 魔網流動 |
| 修煉方式 | 內修為主，吸收轉化 | 外學為主，咒語引導 |
| 力量儲存 | 丹田金丹 | 魔晶/法杖 |
| 施法媒介 | 靈力、符籙、法寶 | 咒語、手勢、材料 |
| 終極目標 | 飛升成仙，超脫輪迴 | 接近神明，掌握真理 |

#### 內修與外學詳細對比

##### 東方內修體系
| 特徵 | 說明 |
|------|------|
| **核心理念** | 「道法自然」——能量本在體內，只需引導覺醒 |
| **修煉方式** | 盤腿打坐，閉目凝神，感知體內經脈與丹田 |
| **能量感知** | 向內感知，感受靈氣在經脈中的流動 |
| **力量來源** | 天地靈氣通過呼吸、毛孔吸收，儲存在丹田 |
| **施法方式** | 掐訣、念咒、御劍，以自身靈力驅動 |
| **優勢** | 力量持久，無需外物，自身即為能量源 |
| **劣勢** | 入門困難，需要長時間靜心修煉，初期進展緩慢 |
| **代表功法** | 劍心通明訣、靈氣感知、丹田儲存 |

##### 西方外學體系
| 特徵 | 說明 |
|------|------|
| **核心理念** | 「知識即力量」——能量在外，需通過學習掌握引導方法 |
| **修煉方式** | 學習咒語、手勢、材料配方，通過實踐掌握 |
| **能量感知** | 向外感知，感受魔網在周圍的流動 |
| **力量來源** | 魔網流動的魔力，通過咒語和手勢引導 |
| **施法方式** | 吟唱咒語、做出手勢、使用材料，引導魔網能量 |
| **優勢** | 入門容易，進展快速，魔法效果立竿見影 |
| **劣勢** | 依賴外物（法杖、材料），施法需要時間準備 |
| **代表魔法** | 火球術、水牆術、火焰護盾 |

##### 內修與外學的互補性
| 面向 | 內修優勢 | 外學優勢 | 融合效果 |
|------|---------|---------|---------|
| **能量感知** | 向內感知，精確控制體內能量 | 向外感知，快速捕捉周圍能量 | 同時感知內外，全面掌控能量 |
| **施法速度** | 無需咒語，意念驅動 | 需要咒語，但效果強大 | 結合兩者，實現瞬發強大魔法 |
| **力量持久** | 自身即為能量源，持久戰優勢 | 依賴魔網，持久戰劣勢 | 自身儲存+魔網補充，無限能量 |
| **入門難度** | 入門困難，但基礎紮實 | 入門容易，但基礎薄弱 | 外學入門+內修鞏固，快速成長 |
| **戰鬥風格** | 近戰為主，劍氣攻擊 | 遠程為主，魔法攻擊 | 遠近兼修，靈活多變 |

#### 統一法則
1. **能量守恆**：氣與瑪那可互相轉化，總量不變
2. **法則同源**：東方所悟的「道」與西方所求的「真理」是同一法則
3. **境界對應**：兩體系境界可一一對應，實力相當
4. **互補優勢**：東方重內修，西方重外學，結合可達更高境界

## 六、核心規則

### 6.1 能量法則
1. **靈源不滅**：氣與瑪那總量恆定，只能轉化不能消滅
2. **境界壁壘**：突破需領悟法則，非單純積累能量
3. **因果循環**：東方稱「因果」，西方稱「命運」，實為同一法則
4. **平衡法則**：力量需平衡，過度使用會遭反噬

### 6.2 修煉/魔法限制
1. **天賦限制**：靈根/魔法天賦決定上限
2. **資源限制**：靈氣/魔力濃度影響修煉速度
3. **心境限制**：心魔/魔法反噬需心境穩定
4. **法則限制**：觸及法則需付出代價

#### 壽命延長機制對比
| 機制 | 東方修仙 | 西方魔法 | 原理說明 |
|------|---------|---------|---------|
| **能量淬鍊** | 靈氣淬鍊肉身，延長壽命 | 魔力重塑生命本源，延長壽命 | 同源能量，不同運用方式 |
| **境界突破** | 每次突破大幅延長壽元 | 每次晉升大幅延長壽命 | 境界/階級對應，壽命增幅相同 |
| **外貌定格** | 金丹期後外貌定格 | 正式法師後外貌定格 | 能量固化生命結構，停止衰老 |
| **神魂不朽** | 元嬰期神魂不滅，可奪舍 | 魔導師靈魂與魔力融合，可轉移意識 | 神魂/靈魂達到不朽狀態 |
| **丹藥/藥劑** | 壽元丹、長生丹等輔助延壽 | 生命藥劑、不朽藥劑等輔助延壽 | 同源材料，不同煉製方式 |
| **法寶/物品** | 養魂玉、補魂珠等溫養神魂 | 靈魂水晶、靈魂寶石等儲存靈魂能量 | 同源能量儲存媒介 |
| **特殊功法/法術** | 長生訣、龜息功等延壽功法 | 生命魔法、時間魔法等延壽法術 | 同源法則，不同表現形式 |

#### 壽命設定注意事項
1. **同源同效**：氣與瑪那本質相同，因此同境界/階級的壽命延長效果完全一致，無優劣之分
2. **外貌與年齡**：金丹期/正式法師以上修煉者外貌定格在突破時，因此 300 歲的角色可能看起來只有 20~30 歲
3. **心理年齡**：雖然外貌年輕，但高境界修煉者擁有數百年的閱歷，心理年齡成熟
4. **戀愛關係**：同境界或相近境界的修煉者，即使實際年齡相差數十歲，外貌與心理年齡都較為匹配
5. **跨體系戀愛**：東方金丹期（500~800 歲壽命）與西方正式法師（500~800 歲壽命）屬於同等級，壽命觀念完全一致
6. **凡人與修煉者**：凡人與修煉者之間的戀愛需考慮壽命差異帶來的悲劇性
7. **體系偏見**：部分保守派認為東方修煉更優越（或西方魔法更先進），但實際上兩者壽命延長效果完全相同，只是方式不同

### 6.4 跨界規則
1. **能量轉換**：氣可轉瑪那，瑪那可轉氣，但需特殊媒介
2. **境界對應**：兩體系境界可比較，但戰鬥方式不同
3. **文化差異**：東方重師徒，西方重學院，理念不同
4. **語言障礙**：需學習對方語言或法術溝通
