# 提示詞生成器 — 聽雨軒

## 📋 項目說明
這是一個互動式提示詞生成工具，用於為 AI 圖像生成模型（如 Midjourney、Stable Diffusion 等）創建細節豐富的角色場景描述。

**角色**: 沈若蘭 (Shen Ruolan) - 一位 22 歲的東方古典氣質女性
**場景**: 聽雨軒 - 一座現代與古典融合的獨棟宅院

## 🚀 功能特性

### 選擇器
1. **場景** (20+): 建築、場所、房間等詳細環境描述
2. **髮型** (7種): 古典到現代各種造型
3. **表情** (4種): 淺笑、沉思、驚訝、憂傷
4. **服裝** (3種): 漢服到現代都市風格
5. **鏡頭** (12種): 各類攝影視角和特寫

### 動態生成
- ✅ 自動組合場景 + 髮型 + 表情 + 服裝 + 鏡頭的完整提示詞
- ✅ 支持額外自訂提示詞
- ✅ 一鍵複製到剪貼板
- ✅ 實時預覽

## 🔧 技術架構

### 核心代碼
- **HTML5** - 語義化結構
- **CSS3** - 響應式設計，深色主題
- **Vanilla JavaScript** - 無框架依賴
- **Fetch API** - 異步資料載入
- **Clipboard API** - 複製功能

### 資料驅動
所有選項都從 `data.json` 動態載入，易於擴充和維護：

```json
{
  "scenes": [{ "id": "foyer", "name": "玄關", "prompt": "..." }],
  "hairstyles": [{ "id": "style_01", "name": "古典低髻", "prompt": "..." }],
  "expressions": [{ "id": "expr_01", "name": "淺笑", "prompt": "..." }],
  "clothings": [{ "id": "clothing_01", "name": "漢服改良常服", "prompt": "..." }],
  "cameras": [{ "id": "camera_01", "name": "正面大頭照", "prompt": "..." }]
}
```

## 📝 如何使用

### 基本使用
1. 在瀏覽器開啟 `index.html`
2. 點選場景、髮型、表情、服裝、鏡頭等選項
3. 在「額外提示詞」區域新增自訂描述（可選）
4. 複製生成的完整提示詞
5. 貼到 AI 圖像生成工具使用

### 新增內容

#### 新增場景
編輯 `data.json`，在 `scenes` 陣列新增：
```json
{
  "id": "new_scene_id",
  "name": "場景名稱",
  "group": "分類名稱",
  "desc": "簡短描述",
  "prompt": "完整英文描述..."
}
```

#### 新增髮型
類同方式，在 `hairstyles` 陣列新增：
```json
{
  "id": "style_XX",
  "name": "髮型名稱",
  "desc": "簡短描述",
  "occasion": "適用場合",
  "prompt": "完整英文描述..."
}
```

#### 新增表情、服裝、鏡頭
同理應用於 `expressions`、`clothings`、`cameras` 陣列。

**無需修改 HTML/JavaScript！所有變更自動適配。**

```json
  "temperament": "古典溫婉，帶有傳統書卷氣",
  "baseDescription": "..."
}
```

## 🔍 故障排除

### 資料無法載入
- 確保 `data.json` 在同一目錄
- 檢查瀏覽器控制台（F12）是否有錯誤訊息
- 嘗試重新整理頁面

### 按鈕無反應
- 確認 JavaScript 已啟用
- 檢查瀏覽器是否支援 ES6+

### 複製功能失效
- 某些舊版瀏覽器不支援 Clipboard API
- 建議使用現代瀏覽器（Chrome/Firefox/Safari/Edge）
