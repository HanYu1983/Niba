# 操作流程與 UI

## 1. 放置棋子
- 玩家在自己的回合，用滑鼠點選一枚己方棋子作為起點。
- 系統高亮顯示所有合法落點。
- 玩家點選一個合法落點完成放置；若該格有敵子則吃子並得分。

## 2. 使用道具
- 玩家在回合內任意時機可開啟道具面板。
- 選擇道具後，進入對應的目標選取模式：
  - 炸彈：點選一枚棋子作為中心。
  - 雷射：點選一格，先指定行或列，再確認施放。
  - 防護：點選一格加上保護。
- 系統需在游標移動時顯示即時預覽（受影響格）。
- 若預覽範圍包含任一主堡，需顯示為無效目標。
- 若目標不合法，需明確提示原因並禁止施放。

## 3. 勝負結算與統計面板
- 觸發時機：任一主堡被佔領，或回合達 100 並以分數決勝。
- 結算內容：
  - 勝負結果（玩家勝 / AI 勝）
  - 終局原因（主堡被佔領 / 回合上限）
  - 雙方分數
  - 總回合數
  - 雙方吃子數
  - 道具使用次數（炸彈 / 雷射 / 防護）
- 操作：
  - 重新開始
  - 回主選單
