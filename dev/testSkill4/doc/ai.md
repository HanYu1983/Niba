# AI 行為與決策規則

## 1. 行為目標
- 優先目標：能吃子就吃子。
- 次要目標：保護己方主堡。
- 第三目標：向玩家主堡擴張。
- 炮的直線移動與吃子最大距離為 10 格。
- 道具使用原則：以最大化效益為目標，不胡亂使用。
  - 優先尋找能造成最大破壞或關鍵防守的道具使用點。
  - 若道具效果與普通放置相比沒有明顯優勢，則保留分數等待更好時機。

## 2. 道具決策（量化規則）
### 2.1 通用評分
- AI 會為每個可用道具計算最高可行分數，分數最高者才會使用。
- 若最高分 < 2，AI 會保留分數不使用道具。

### 2.2 炸彈評分
- 分數 = (炸死玩家棋子數 x 2) - (炸死己方棋子數 x 3) + 防守加成
- 防守加成：若爆炸會清除靠近己方主堡 2 格內的玩家棋子，+3。
- 若爆炸範圍包含任一主堡，該方案無效。

### 2.3 雷射評分
- 分數 = (破壞玩家棋子數 x 2) - (破壞己方棋子數 x 3) + 進攻加成
- 進攻加成：若雷射能清出通往玩家主堡的直線通道，+2。
- 若雷射路徑包含任一主堡，該方案無效。

### 2.4 防護評分
- 分數 = (保護格的重要度) + (預測被吃子風險)
- 重要度：己方主堡 +5；主堡相鄰格 +3；其他棋子 +1。
- 風險：若玩家下一回合存在可吃該格的合法馬步，+3；否則 +0。
- 若該格已有防護，該方案無效。

## 3. 行為流程（文字版）
1. 取得所有可放置的合法位置。
2. 計算可吃子位置；若存在則優先挑選高價值吃子（靠近玩家主堡者優先）。
3. 若分數足夠，對每種道具計算最高評分：
   - 若最高分 >= 2，使用該道具。
   - 否則保留分數。
4. 若未使用道具：
   - 先執行防守性放置（主堡 2 格內的威脅）。
   - 否則執行進攻性放置（朝玩家主堡擴張）。
5. 結束回合。
