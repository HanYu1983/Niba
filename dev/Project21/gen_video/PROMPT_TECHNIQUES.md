---

## 0. 一句話

**台詞是給 TTS 唸的，不是給人讀的。**

凡是 TTS 不該唸的東西（引號、冒號、`%`、阿拉伯數字、英文、強調符號）出現在台詞裡，都可能被唸出來，或在該處插入、重讀、跳針。這三個 QA 其實是同一件事的三種症狀。

---

## 1. 三條鐵律

1. **純中文可唸文字**：台詞裡只出現唸得出來的國字與標點。
2. **一行一個語意單元**：每句獨立換行、以句號收尾。
3. **Action 不複述台詞**：動作欄只寫語氣、動作、語意方向，不要提供第二份「可唸文本」。

---

## 2. 符號：會被唸出來的一律拿掉（Q2）

| 寫法 | 實測症狀 | 改成 |
|---|---|---|
| `「」`、`『』` | 括引本身被唸出怪音（連專有名詞的括引也會） | 直接寫文字：`「標籤之雨」` → `標籤之雨` |
| `：`（句中全形冒號） | 句子被攔腰切斷，前段重讀或插入怪對白 | 改成句號，拆成兩句 |
| `%` | 被唸成「PiFen」 | `百分之二`、`百分之十五` |
| 阿拉伯數字 | 讀法不穩、易混英文 | `45` → `四十五`；**禁止混寫** `百分之2` |
| `&`、`#`、`@`、emoji | 被當成要唸的內容 | 移除 |
| `*`（強調）、裝飾符號 | 不屬於台詞 | 移除 |
| `——`（em dash） | 斷句處被當成切點 | 改成句號或逗號 |
| `……` | 多數情況可作氣口 | 保留；若出現怪音就改句點 |
| 英文／中英混寫 | 直接唸英文或混雜語言 | 改純中文；`伺服器`、`開源論壇` 這類借詞若在句中斷點，容易觸發外語輸出 |

補充：

* **畫面可見文字**（圖表數字、電視牆標題、報紙頭條）不會被唸出，可以保留原始符號；但必須寫在鏡頭描述裡並標 `visible on-screen text`，與台詞分開。
* 腔調錨點只排除方言（`no Cantonese`）**不排除外語**；角色外觀偏西方也會誘發外語。這兩點是 Q1 的範圍，但寫台詞時要一起考慮。

## 3. 分行：一句一行，單行不超過 20 字（Q3、Q4）

### 症狀

* **Q3**：13 秒長對白整段寫成一行，兩句之間被插入一段奇怪的對白。
* **Q4**：27 字單行、句中含 `：`，「玩一個」被重複唸兩次（跳針）。

### 原因

TTS 逐句處理，**換行就是氣口**。一行裡塞進多個語意單元、又用冒號攔腰切斷，模型在切點失去停頓依據，就會自行腦補：要嘛插話（Q3），要嘛把前半段重讀一次再對軌（Q4）。

### 規則

* 每個**完整句**獨立一行，句號收尾。
* 單行控制在 **≤ 20 字**或 **≤ 7–10 秒**；超過就拆。
* 一句只能有一個語意單元。`A：B` 這種「主題＋說明」的句子，一律拆成 `A。B。`
* 不要為了排版在**逗號**處斷行——半句斷行等於告訴模型「這裡可以插話」（Q14 同源）。

---

## 4. Action 欄不要提供第二份台詞（Q3 因子 3）

`Action` 用英文把台詞語意複述一次（`…not only talking in the square — he has synced that server's…`），等於額外交給模型一份「可唸文本」，而 em-dash 的斷點剛好對上句中切點，模型就拿它來插話。

規則：

* 只寫**語氣＋動作＋語意方向**，例如 `He speaks quietly, jaw tight, never raising his voice.`
* 不照抄台詞、不翻譯台詞、不用 em-dash 重現台詞節奏。
* 抽象詞（政治動員、認知反偵察）附近不要放英文對譯。

---

## 5. 修正後一定要換 seed

seed 與腔調、發音耦合。**固定 seed 再怎麼改文字都不會生效**，只會得到同一個歪腔／跳針結果。

* 每次修正提示詞 → 換新 seed 重跑。
* 歪腔、性別翻轉、跳針的 seed 記進黑名單。
* 旁白區塊共用同一支旁白 seed 是有效的，但該 seed 一旦翻轉聲線性別就整支作廢。

## 6. 對照到本專案的分鏡 JSON

| 舊管線（Project20） | 本專案（`gen_video` 編譯器） |
|---|---|
| `<d>` 台詞 | `blocks[].audio_control.dialogue.original_text` |
| `Action` | `blocks[].action.description` |
| `overall_soundscape` | `blocks[].audio_control.soundtrack_specification` |
| `speaker_constraints` | `blocks[].audio_control.dialogue.voice_prompt` |
| `detailed_description` | `action.description` ＋ `present_characters` |

**關鍵分工**：`plan.json` 的 `spoken_text` 是**逐字原文**（要能併回小說、供查核），不要為了 TTS 去改它；清理發生在第二階段，把 `spoken_text` 轉成可唸的 `original_text`：

```
spoken_text（逐字，可含「」『』——：）
      ↓ 移除引號、破折號、冒號；數字改中文
original_text（純中文、一句一行）
      ↓
audio_control.dialogue.original_text
```

### 本章實例

| 出處 | 逐字原文 | 可唸版本 |
|---|---|---|
| `seg_001` 旁白 | 而是他的恩師——曾被譽為「司法界最後良心」的退休法官趙立廷。 | 而是他的恩師，曾被譽為司法界最後良心的退休法官趙立廷。 |
| `seg_008` 獨白 | 其他的證人指認——那些趙前輩曾經得罪過的政客——難道不是一場集體的構陷？ | 其他的證人指認，那些趙前輩曾經得罪過的政客，難道不是一場集體的構陷？ |
| `seg_021` 對白 | 「好險，」……**「好險我那天沒讓那種『想當英雄的癮頭』給毀了。……」** | 好險，好險我那天沒讓那種想當英雄的癮頭給毀了。／好險我只是個冷酷的、看見事實的人。 |

`seg_021` 這句 36 字、9 秒，已超過單一鏡頭上限，所以 plan 標 `render_blocks: 2`——**拆行與拆塊要對齊**：兩個 block 的分界就落在句號處，不要一個 block 唸到半句。
