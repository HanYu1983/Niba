在 GCP 上增加硬碟空間非常方便，你不需要重新建立 VM，可以直接在「不關機」的情況下動態擴充。

以下是操作的三大步驟：

### 1. 在 GCP 控制台修改磁碟大小

首先，你要告訴 Google Cloud 你需要更多空間。

1. 進入 **Compute Engine > 磁碟 (Disks)**。
2. 點擊你的 VM 所使用的那個磁碟名稱（通常與 VM 同名）。
3. 點擊上方的 **「編輯 (EDIT)」**。
4. 將「大小」從 100 改為你需要的數字（例如 **200 GB**）。
5. 點擊 **「儲存」**。
* *注意：磁碟只能調大，不能調小。*



---

### 2. 在 Linux 系統內擴展分區 (Partition)

雖然 Google Cloud 把「實體硬碟」變大了，但 Linux 系統內的「分區」還是舊的大小。你需要手動推它一把。

請 SSH 進入 VM 並執行：

```bash
# 1. 確認你的磁碟代號（通常是 /dev/sda）
lsblk

# 2. 自動擴展分區 (假設是 /dev/sda 的第 1 個分區)
sudo growpart /dev/sda 1

```

---

### 3. 擴展檔案系統 (File System)

最後一步是讓檔案系統（如 ext4）佔滿整個新空間。

```bash
# 如果你的檔案系統是 ext4 (Debian/Ubuntu 預設)
sudo resize2fs /dev/sda1

# 如果你的檔案系統是 xfs
sudo xfs_growfs /

```

**檢查結果：**
執行 `df -h`，你應該會看到根目錄 `/` 的容量已經變大了。

---

### 💡 進階建議：使用「額外掛載磁碟」而非擴大系統碟

如果你未來打算放很多 ComfyUI 模型，我建議**不要**無限制擴大系統碟（Boot Disk），而是**新增一顆額外的資料碟**。

**好處：**

* **解耦：** 如果 VM 系統搞壞了要重灌，你的模型資料都在另一顆磁碟上，直接掛載到新 VM 即可。
* **成本靈活：** 系統碟可以用較貴的 SSD，存放模型的資料碟可以用較便宜的「平衡永久磁碟」。
* **快照備份：** 你可以單獨為模型磁碟做快照。

**操作方式：**
在 VM 設定頁面點擊 **「新增磁碟 (ADD NEW DISK)」**，然後在 Linux 裡執行 `mkfs` 格式化並 `mount` 到 `~/ComfyUI/models`。

從你的 `lsblk` 輸出可以看到，你的實體磁碟 `nvme0n1` 已經成功擴展到 **300G** 了，但你的根目錄分區 `nvme0n1p1` 仍然卡在 **99.9G**。

這就是我提到的「硬碟變大了，但隔間（分區）還沒推開」。因為你的磁碟代號是 **nvme**，指令需要稍微修正：

---

### 1. 擴展分區 (Resize Partition)

請執行以下指令，將第 1 號分區推滿整個磁碟：

```bash
sudo apt-get install -y cloud-guest-utils fdisk
sudo growpart /dev/nvme0n1 1

```

* **注意：** `/dev/nvme0n1` 與 `1` 之間有一個**空格**。
* 執行完後，你可以再打一次 `lsblk`，應該會看到 `nvme0n1p1` 的 SIZE 變成了接近 300G。

---

### 2. 擴展檔案系統 (Resize Filesystem)

分區推開後，要讓 Linux 的檔案系統（ext4）意識到空間增加了：

```bash
sudo resize2fs /dev/nvme0n1p1

```

---

### 3. 最後驗證

執行以下指令確認空間是否正確釋放：

```bash
df -h /

```

你應該會看到 `/` 的 `Size` 欄位顯示為 **290G+** 左右。

---

### 💡 為什麼代號不一樣？

* **sda**：通常出現在傳統的虛擬化磁碟（SCSI）。
* **nvme0n1**：出現在 GCP 較新的機器類型（如 N2, C3 等）或是高效能磁碟，速度比 sda 快很多。
