# 檔案名稱：Combat_Module.md

## 1. 戰鬥流程 (Combat Phase: The Nightly Purge)
- **觸發時機**：每回合「執行卡牌」與「研發科技」結束後，系統進入夜間防禦模式。
- **作戰形式**：自動化回合制。玩家無法即時操作，僅能依賴白天布置的 [防禦裝備] 與解鎖的 [主動技能]。
- **勝負判定**：
    - **成功**：消滅所有敵方單位，獲得微量「情緒殘留」RP。
    - **失敗**：未消滅的敵方單位將對 [物理防禦值 (HP)] 造成直接傷害。

## 2. 屬性剋制系統 (Counter Mechanism)
所有敵方情緒與防禦裝備分為三種邏輯屬性，形成互剋環：

| 屬性類型 | 代表情緒 | 剋制關係 | 邏輯描述 |
| :--- | :--- | :--- | :--- |
| **燥紅 (Thermal)** | 憤怒、狂喜 | 剋制 **森綠** | 劇烈的情緒波動會燒毀理性的防線。 |
| **森綠 (Organic)** | 懷念、愛、遺憾 | 剋制 **幽藍** | 複雜的人性連結能穿透冰冷的邏輯。 |
| **幽藍 (Logic)** | 憂鬱、麻木、冷漠 | 剋制 **燥紅** | 絕對的冷靜能輕易熄滅怒火。 |

## 3. 防禦裝備庫 (Defense Modules)
玩家需利用 RP 解鎖並在控制台裝備。裝備位有限（初始 3 格）。

| 裝備名稱 | 屬性 | 效果說明 | 科技線要求 |
| :--- | :--- | :--- | :--- |
| **白音牆 (Static Wall)** | 幽藍 | 基礎防壁，對「燥紅」單位有高額減傷。 | 初始解鎖 |
| **邏輯掃射器 (Logic Gatling)** | 幽藍 | 高頻率單體攻擊，優先鎖定憤怒單位。 | 效率線 20% |
| **共感阻斷器 (Empathy Jammer)** | 森綠 | 降低區域內「藝術家」單位的特殊技能發動率。 | 技能線 20% |
| **熱力消耗儀 (Heat Sink)** | 燥紅 | 將敵方的憤怒轉化為防禦塔的攻擊速。 | 技能線 40% |

## 4. 敵方單位類型 (Antagonists)

### A. 情緒心魔 (The Ego Echoes)
- **特性**：由棄牌或區域混亂產生。
- **行為**：直接衝撞控制台，行為單一但數量眾多。

### B. 地下反抗者 (The Underground)
- **特性**：來自未平坦化的區域（尤其是藝術區）。
- **行為**：具備「光環效果」，能提升周圍心魔的攻擊力，或暫時封鎖玩家的防禦設施。

## 5. 戰鬥結算與損耗 (Aftermath)
- **維修成本**：每晚結束後，根據物理防禦值損失量，自動扣除 RP 進行修復。
- **恐懼積累**：若防禦成功且為「完勝」，地圖整體的 [暴動值] 會因為玩家的強力鎮壓而暫時下降，但 [警覺感] 會提升。

## 6. 主動干預技能 (Active Intervention)
若玩家在「技能線」有投入，可在戰鬥開始前選擇一個干預方案：
- **[超載負載]**：本晚防禦力倍增，但下回合 [系統穩定度] 強制下降 10。
- **[誘餌數據]**：犧牲一張隨機手牌，引誘敵方轉向攻擊虛擬區域，保護控制台。
