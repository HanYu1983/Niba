# 檔案名稱：Numerical_Design.md（數值企劃）

> 本文件定義《靜默協議》中所有關鍵數值的區間、公式與設計錨點，供實作與平衡調參使用。與 [Metrics_Impact_Analysis.md]、[Tech_Tree.md]、[Card_Attributes.md] 等互為補充。

## 1. 核心勝負與生命值

| 數值名稱 | 範圍 | 初始值 | 說明 |
| :--- | :--- | :--- | :--- |
| **物理防禦值 (HP)** | 0 ~ 100 | 100 | 歸零即 Game Over。僅在晚間防禦失敗時扣除。 |
| **系統穩定度 (Stability)** | 0 ~ 100 | 100 | 歸零即 Game Over。受卡牌執行、棄牌洩漏、事件卡、主動技能影響。 |
| **系統穩定度上限** | — | 100 | 部分事件卡（如「系統崩潰預兆」）會永久扣除此上限（見 Tech_Tree）。 |
| **格式化進度** | 0% ~ 100% | 0% | 全地圖情緒飽和度歸零時達 100%，即勝利。 |

**設計錨點**：雙敗北條件數值一致（皆 0~100），方便玩家直覺理解「兩條命」。

## 3. 系統穩定度：閾值與效果

與 [Metrics_Impact_Analysis.md] 對齊，以下為可實作的具體數值：

| 區間 | 數值範圍 | 效果（實作用） |
| :--- | :--- | :--- |
| 高 | > 80 | RP 提煉時 5% 機率獲得 **額外 +50% 該次 RP**（小獎勵）。 |
| 中 | 40 ~ 80 | 執行「區域專屬高階卡」時，該卡對穩定度的損耗 × **1.2**。 |
| 低 | 1 ~ 39 | 手牌中「系統事件卡」的 **觸發／強制生效機率 × 2**（若該卡有機率判定）。 |
| 歸零 | 0 | Game Over。 |

**設計錨點**：40、80 為兩個關鍵門檻，讓玩家有明確「安全區／危險區」感受。

## 4. 區域暴動值 (Riot)：閾值與效果

| 區間 | 數值範圍 | 效果（實作用） |
| :--- | :--- | :--- |
| 低 | 0 ~ 30 | 該區提煉 RP 正常；晚間生成敵方數量與強度為 **基礎值 × 1.0**。 |
| 中 | 31 ~ 70 | 在該區執行卡牌時，該卡造成的 **系統穩定度損耗 × 2**。 |
| 高 | 71 ~ 100 | 每回合向 **每個相鄰區域** 蔓延暴動 **+5**；敵人強度係數 **× (1 + Riot/100)**（例：Riot=80 → 1.8×）。 |
| 蔓延（Map_Strategy 補充） | Riot > 80 | 每回合額外向相鄰區域擴散 **該區暴動值的 10%**（向下取整）。 |

**暴動值範圍**：0 ~ 100，超過 100 以 100 計（或設計為溢出轉為全局警覺感 +1，可選）。

## 5. 警覺感 (Alertness)：閾值與效果

| 區間 | 數值範圍 | 效果（實作用） |
| :--- | :--- | :--- |
| 低 | 0 ~ 20 | 晚間僅生成心魔；抽牌池為純情境卡 + 依科技／熱負載加入的事件卡。 |
| 中 | 21 ~ 60 | 抽牌池混入 **干擾卡**；機率建議：**(Alertness - 20) / 100**（例：40 警覺 → 20% 干擾卡）。 |
| 高 | 61 ~ 100 | 晚間有機率出現 **高級反抗者 (Boss)**；機率建議：**(Alertness - 60) / 40**（線性至 100%）。 |

**警覺感範圍**：0 ~ 100。每回合自然衰減可選（例如每回合 -1，避免永久鎖死高難度）。

## 6. 情緒飽和度與平坦化

| 數值名稱 | 範圍 | 說明 |
| :--- | :--- | :--- |
| 情緒飽和度（每區） | 0% ~ 100% | 執行情境卡時依卡牌設計減少該區飽和度（見卡牌數值）。 |
| 平坦化條件 | 飽和度 = 0% | 該區進入灰階，不再產情境卡、不再受攻擊；解鎖區域專屬獎勵。 |

**設計錨點**：單區歸零即有獎勵，但全區過早平坦化會導致無卡可抽；需透過「每區飽和度下降幅度」與「牌池產出」平衡。

## 7. 科技樹數值

### 7.1 研發成本（指數成長）

建議公式（可依關卡長度微調）：

- 設 **總研發等級** \( L = \text{Efficiency}_\% + \text{Skill}_\% \)（例如兩線各 25% → L = 50）。
- **下一格研發成本**（該線下一個 25% 節點）：
  \[
  \text{Cost}(L) = \lfloor 30 \times 1.15^L \rfloor
  \]
  - 例：L=0 → 30 RP；L=50 → 約 30×1.15^50 需再依實際遊玩調整倍率與底數。
- **簡化版（錨點）**：第一格 30 RP、第二格 40、第三格 55、第四格 75、第五格 100…（每條線 4 格即 25%~100%）。

| 進度節點 | 建議單格成本 (RP) |
| :--- | :--- |
| 0% → 25% | 30 |
| 25% → 50% | 45 |
| 50% → 75% | 65 |
| 75% → 100% | 90 |

（以上為單線；雙線獨立計算，即效率線與技能線各自有一套 30→45→65→90。）

### 7.2 熱負載 (Thermal Load)

- **公式**：\( \text{Total\_Heat} = (\text{Efficiency}_\% \times 1.2) + (\text{Skill}_\% \times 1.2) \)
- **閾值**：Total_Heat > 100 時，每回合抽到「負面／系統事件卡」的 **基礎機率 10% → 40%**（與牌池內事件卡數量一起決定實際抽中率）。

### 7.3 終極解鎖

- **格式化權限**：兩線總進度合計 ≥ **150%**（例如效率 75% + 技能 75%）。
- 解鎖後可使用「徹底淨化」指令，成本見 §9。

## 8. 卡牌數值區間標準

與 [Card_Attributes.md] 對齊，以下為情境卡設計時的建議區間（事件卡、淨化卡另見各文件）。

### 8.1 情境卡（Scenario）

| 屬性 | 低階 | 中階 | 高階 | 說明 |
| :--- | :--- | :--- | :--- | :--- |
| **RP 產出** | 10 ~ 25 | 26 ~ 40 | 41 ~ 55 | 高 RP 卡建議搭配較高代價。 |
| **穩定度損耗** | 0 ~ -2 | -3 ~ -5 | -6 ~ -10 | 通常為負值，即扣除穩定度。 |
| **暴動值增幅** | 0 ~ +3 | +4 ~ +7 | +8 ~ +12 | 對目標區域。 |
| **警覺感加權** | 0 ~ +2 | +3 ~ +5 | +6 ~ +10 | 全球。 |
| **飽和度減少** | 3% ~ 6% | 7% ~ 12% | 13% ~ 20% | 對目標區域，依「治理強度」設計。 |

**設計錨點**：單卡淨收益（RP 換算成「可買回的穩定度／風險」）建議大略平衡，高報酬高風險。

### 8.2 系統事件卡

- 多為 **不可棄置**、**佔用手牌**；若持有多回合未處理，可設計為每回合 **系統穩定度 -1** 或 -2（在數值企劃中統一為 -1 易於記憶）。

### 8.3 淨化卡（Purify）

- **消耗**：建議 80 ~ 150 RP（解鎖「徹底淨化」後可依 Tech_Tree 設為永久 -50% 成本）。
- **效果**：指定區域飽和度歸零並平坦化（若已為「治理良好」等條件，依設計書）。

## 10. 戰鬥相關數值

### 10.1 敵方強度係數（與暴動、警覺掛鉤）

- **心魔基礎攻擊力**：設基值 5；實際 = \( 5 \times (1 + \text{該區 Riot}/100) \times \text{警覺係數} \)。
  - **警覺係數**：0~20 → 1.0；21~60 → 1.0 + (Alertness-20)/80；61~100 → 1.5 + (Alertness-60)/80（可簡化為 1.0 ~ 2.0 線性）。
- **心魔數量**：建議每區每晚 **1 + floor(Riot/25)** 隻（低暴動 1 隻，高暴動 4 隻）。
- **Boss 出現**：警覺 ≥ 61 時，每晚機率 **(Alertness - 60) / 40**，1 隻。

### 10.2 防禦與傷害

- **白音牆**（初始）：減傷率對燥紅 40%，其餘 15%。
- **邏輯掃射器**（效率 20%）：攻擊力 +8，對燥紅加成 50%。
- **共感阻斷器**（技能 20%）：藝術家單位技能發動率 -30%。
- **熱力消耗儀**（技能 40%）：敵方燥紅單位攻擊轉化為己方攻速加成 20%。

（以上百分比可依實作平衡微調。）

### 10.3 維修成本（晚間結算）

- **公式**：**損失的物理防禦值 × 2 = 需扣除的 RP**（不足則扣至 0 RP，物理防禦值可保持受損狀態直至修滿或下次受損）。
- 工業區平坦化後：維修成本 **× 0.7**。

### 10.4 戰鬥獎勵

- **完勝**（全滅敵方）：獲得 **5 ~ 15 RP**（情緒殘留）；暴動值全區 **-2**；警覺感 **+1**。

## 14. 危機感評估與數值改進建議（數值企劃觀點）

### 14.1 當前數值能否給玩家危機感？

| 面向 | 現狀 | 評估 |
| :--- | :--- | :--- |
| **雙敗北條件** | HP / 穩定度皆 100，歸零即死 | ✅ 結構清晰。但 100 點若損耗偏慢，前段容易「無感」。 |
| **穩定度損耗** | 單卡 -2～-10；中暴動區 ×2 | ⚠️ 開局四區暴動 5/8/10/15，全在 0～30「低暴動」，等於前幾回合損耗從未 ×2，**前期幾乎沒有穩定度危機**。 |
| **物理防禦 (HP)** | 僅晚間戰鬥扣血；心魔基傷 5、數量與 Riot 掛鉤 | ⚠️ 開局敵少、Riot 低，第一晚傷害可能極低，**HP 條很長一段時間可能幾乎不動**，危機感延後。 |
| **暴動蔓延** | 71+ 每回合鄰區 +5；>80 再擴散 10% | ✅ 一旦進入高暴動，蔓延會讓危機快速升溫。但 **71 與初始 5～15 距離遠**，觸發偏晚。 |
| **警覺感** | 0～100，無自然衰減（可選） | ✅ 只升不降時，會形成長期壓力，利於危機累積。 |
| **資源 (RP)** | 初始 50、首格科技 30；卡牌產出 10～55 | ✅ 略緊，取捨有意義。若再加上維修、技能消耗，有機會出現「沒 RP 修/沒 RP 降暴動」的抉擇。 |

**小結**：機制本身能支援危機感，但 **前期數值偏寬鬆**（穩定度損耗未因暴動放大、HP 不易掉、暴動門檻 71 偏晚），容易導致前 10～15 回合緊張感不足。中後期一旦暴動與警覺上來，危機會明顯加重。

---

### 14.2 建議改進方向（保留現有架構微調）

#### A. 讓「穩定度」前期就有感

- **方案 1**：增加**每回合基礎穩定度壓力**。例如每回合結算時 **穩定度 -1**（或 -2），代表系統持續負荷；可搭配「平坦化某區時 +3～5 穩定度」作為回饋，讓決策有救贖感。
- **方案 2**：**調低「中暴動」門檻**，例如 31～70 改為 **21～60**，讓 1～2 區較快進入「在此區打牌穩定度損耗 ×2」，前期就有取捨壓力。
- **方案 3**：**調高初始暴動**，至少一區（如藝術區）設為 **25～35**，使開局就有一區瀕臨或進入中暴動，第一輪決策就受影響。

#### B. 讓「物理防禦」不至於長期滿血

- **方案 1**：設定**每晚最低傷害**（例如 1～3 點），即使敵方被壓制，控制台仍承受微量損傷，HP 條每回合都有變化。
- **方案 2**：**心魔基礎攻擊力**由 5 微調為 **6～7**，或**每區最低敵數**設為 1（目前已是 1+floor(Riot/25)，Riot=0 時為 1），確保每晚至少有一定傷害基數。

#### C. 讓「暴動」更早進入危險區

- **方案 1**：**蔓延門檻**由 71 降為 **60**（或 65），高暴動蔓延提早 1～2 回合觸發。
- **方案 2**：維持 71，但**中暴動區 (31～70) 每回合自然 +1 暴動**（代表未鎮壓區持續升溫），避免玩家「放生」一區卻長期不付出代價。

#### D. 穩定度「有機會回升」避免絕望螺旋

- 若採用 **每回合 -1 穩定度**，建議搭配：
  - **平坦化任一區**：穩定度 **+5**（或 +3）；
  - 或 **警覺感 < 20 且本回合未執行高風險卡**：穩定度 **+1**（上限 100）。
- 讓「穩紮穩打、先壓一區」有明確回報，低穩定度時仍有翻盤空間，而不是一路滑到歸零。

#### E. 警覺感設計明確化

- **建議**：**不提供警覺感自然衰減**，維持「只升不降」，讓高警覺成為長期成本，強化危機感。
- 若希望後期有喘息，可改為「每平坦化一區，警覺感 -5」等有條件衰減，並在文件中寫明。

#### F. 危機節奏與回饋（建議寫入 UI / 敘事規範）

- **穩定度 < 40**：建議 UI 強警示（顏色/音效/簡短日誌），讓玩家明確感到「瀕危」。
- **任一區暴動首次 ≥ 71**：建議觸發一次明確回饋（日誌或提示），標記「該區已失控、開始蔓延」。
- **警覺感首次 ≥ 61**：建議標記為「Boss 階段開始」，敘事或 UI 標示關鍵轉折。
- **可選**：若連續 N 回合（如 5）未平坦化任何區域，則全區暴動 +2 或警覺 +1，避免玩家無限拖延而無壓力。

### 14.3 建議採用的具體數值調整（可選一組或混用）

| 項目 | 現值 | 建議 | 目的 |
