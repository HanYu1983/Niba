# 檔案名稱：Tech_Tree.md

## 1. 研發基本邏輯 (Research Logic)
- **核心資源**：研究點數 (Research Points, RP)，由情境卡提煉獲得。
- **解鎖規則**：非線性解鎖。玩家可自由分配 RP 於兩大分支，但隨總等級提升，研發成本將呈指數成長。
- **負擔機制**：每條路線每解鎖 **25% 進度**，系統強制向玩家牌堆（Deck）中永久加入一張對應的 **[系統事件卡]**。

## 2. 效率線：自動化與產能 (Efficiency Branch)
*目標：極大化資源獲取，降低系統維持成本。適合追求快速擴張與進度的玩家。*

| 進度 | 科技名稱 | 效果描述 | 伴隨系統事件卡 |
| :--- | :--- | :--- | :--- |
| **25%** | **情緒過濾算法** | 提煉資源時，[系統穩定度] 的損耗降低 20%。 | **[數據垃圾溢出]**：不可棄置，本回合所有產出減半。 |
| **50%** | **批次處理模組** | 解鎖「棄牌回收」，棄置卡牌可獲得其 30% 的點數。 | **[邏輯冷感]**：佔位卡，持有期間無法對「藝術區」進行任何操作。 |
| **75%** | **高頻收割協議** | 每回合抽牌數從 1 張變為 2 張 (仍維持每回合執行 1 張)。 | **[數據黑洞]**：不可棄置，本回合結束時隨機刪除一張手牌。 |
| **100%** | **極致純白進程** | 格式化區域所需的點數成本永久降低 50%。 | **[系統崩潰預兆]**：不可棄置，[系統穩定度] 上限永久扣除 20。 |

## 3. 技能線：干預與防禦 (Skill Branch)
*目標：提供危機應對手段，強化物理防禦與地圖控制。適合穩紮穩打、應對突發狀況。*

| 進度 | 科技名稱 | 效果描述 | 伴隨系統事件卡 |
| :--- | :--- | :--- | :--- |
| **25%** | **輿論冷卻劑** | 解鎖主動技能：消耗點數，直接清除指定區域的 [暴動值]。 | **[虛假回報]**：佔位卡，本回合執行任何卡牌皆不獲得點數。 |
| **50%** | **自動化防禦塔** | 晚間自動防禦階段，基礎攻擊力增加 50%。 | **[軍備競賽]**：地圖上所有心魔與抗議者的強度等級提升。 |
| **75%** | **情緒模擬器** | 允許將一張手牌的屬性臨時轉變為指定區域屬性。 | **[感知錯亂]**：本回合所有手牌數值與效果隱藏，需盲選。 |
| **100%** | **絕對零度領域** | 戰鬥技能：立即停止本晚所有敵人的行動（冷卻 3 回合）。 | **[孤立無援]**：佔位卡，持有期間所有區域的被動收益停止。 |

## 4. 決策平衡：系統熱負荷 (Thermal Load)
為了防止玩家無代價點滿雙線，導入熱負荷機制：
- **公式**：$$Total\_Heat = (Efficiency\_Lv \times 1.2) + (Skill\_Lv \times 1.2)$$
- **閾值效應**：當 $Total\_Heat > 100$ 時，每回合抽到「負面事件卡」的基礎機率由 10% 提升至 40%。

## 5. 終極解鎖：格式化權限 (Format Permission)
- **解鎖條件**：兩條線總進度合計達到 **150%**。
- **最終功能**：解鎖對「治理良好」區域的 **[徹底淨化]** 指令，將區域轉為純白灰階，移除該區所有威脅與互動，向 100% 格式化進發。
