# MiniMax H3 提示詞抓取方法

## 網站

- 主畫廊頁：https://beatapi.io/zh/minimax-h3-prompts
- 開源倉庫：https://github.com/BeatAPI/awesome-minimax-h3-prompts

## 抓取流程

1. 用 WebFetch（markdown 格式）抓主畫廊頁。
2. 在「## 全部提示词」區段，每個案例的「查看詳情」連結即為詳情頁 URL，格式如：
   `https://beatapi.io/zh/prompts/minimax-h3/<案例slug>-<id>`
3. 逐一用 WebFetch（markdown 格式）抓詳情頁。
4. 詳情頁結構固定：
   - 標題（案例名）
   - 「Prompt」段落後即完整提示詞原文（含時間軸、台詞、負面約束）
   - 「模型 MiniMax H3」「時長」「畫面比例」「來源 @作者」
   - 底部有 X 原帖連結（「在 X 上打開來源」）
5. 存成 md：檔名 `H3範例NN_<主題>.md`，內容包含
   來源作者、X 連結、詳情頁連結、時長、畫幅、完整提示詞原文、結構要點摘要。

## 注意事項

- 主頁一次只列出約 24 個案例（24/300），其餘需點「加載更多」。
- 詳情頁 URL 的 slug 可能含中文轉碼或數字 ID，直接複製「查看詳情」href 即可。
- 提示詞原文保留英文不翻譯；結構要點用中文摘要。
- 每頁一個案例，建議一次抓 5 個為一批，避免超長回應被截斷。
