# 生圖提示詞範本指南（Prompt Template Guide）

給 AI（opencode / 其他助手）參考用的「如何下提示詞」文件。
搭配 `ai_gen/index.js` 的 `--vars` 替換機制使用。

---

## 一、替換機制（index.js --vars）

`index.js` 會讀入一個外部 JSON，把提示詞裡的 `{{token}}` 換成 JSON 對應值。

**CLI 用法：**

```cmd
docker compose run --rm comfy-client node index.js --vars prompt.json --seed 12345 --out output
```

**JSON 結構（`prompt.json`）：**

```json
{
  "character": "銀白色長髮少女",
  "clothing": "白色針織毛衣與牛仔裙",
  "action": "坐在窗邊托腮微笑",
  "scene": "雨夜的咖啡店，黃暖燈光",
  "style": "寫實日系插畫，電影感光影，8k",
  "prompt": "{{character}}，身穿{{clothing}}，{{action}}，場景：{{scene}}，{{style}}"
}
```

規則：
- 提示詞中出現 `{{key}}` 就替換；沒有該鍵 → 保留原樣（方便發現缺漏）。
- 沒給 `--prompt` 時，直接用 JSON 的 `prompt` 欄位。
- JSON 內可加 `seed` 欄位（沒給 `--seed` 時使用）。
- 無關的額外欄位（人物、服裝、動作……）照樣會被替換，只是「資料」。

## 二、提示詞撰寫結構（分層）

建議按以下層次組裝，Z-Image 對中文自然語言理解極佳：

| 層 | 內容 | 範例 |
|---|---|---|
| 角色 | 髮型、年齡感、特徵 | 銀白色及腰長髮，琥珀色眼睛 |
| 服裝 | 上衣/下裝/配件 | 白色針織毛衣、牛仔裙、貝雷帽 |
| 動作與姿態 | 肢體語言、視線、表情 | 托腮、側坐、淺淺微笑看向鏡頭 |
| 場景 | 地點、時間、氛圍 | 雨夜咖啡店、窗邊、暖黃燈光 |
| 情緒/張力 | 兩人之間的距離感 | 初次見面、微妙的緊張與好奇 |
| 鏡頭 | 景別、拍攝法 | 中景、45 度、淺景深 |
| 風格/品質 | 風格詞 + 品質詞收尾 | 寫實日系插畫、電影級光影、極致細節、8k |

**組成公式：**

```
角色＋服裝＋動作＋場景＋情緒＋鏡頭＋風格品質
```

**撰寫要點：**
1. 角色先寫「可辨識的外觀錨點」（髮色/瞳色/服裝），再寫情緒。
2. 動作要具體：不要只寫「牽手」，要寫「她慢慢地伸出手，與他十指相扣」。
3. 情緒用「距離感」描述，畫面會更有故事（見階梯表）。
4. 每張圖固定語言一致（避免中英混雜造成風格漂移）。

## 三、親密感階梯（Lv1 陌生 → Lv5 親密）※ 範本上限 PG-13

此為「從陌生到親密」的示範動作分級，供下提示詞時挑選。**只到 PG-13：牽手、擁抱、依偎、輕吻臉頰／額頭。不包含性內容。**

| Lv | 情緒 | 動作示範（可直接替換 {{action}}） |
|---|---|---|
| Lv1 陌生 | 戒備、好奇 | 保持一臂距離，側身，視線游移，手指不安地繞衣角 |
| Lv2 認識 | 放鬆、試探 | 並肩坐著聊天，她轉頭看他，輕笑，手不經意碰在一起又縮回 |
| Lv3 好感 | 心動、在意 | 遞上暖飲，肩靠著肩看窗外，共用一副耳機 |
| Lv4 曖昧 | 緊張、甜蜜 | 十指相扣，她靠在他胸膛，額頭相抵，鼻尖幾乎碰觸 |
| Lv5 親密 | 安心、依賴 | 依偎在他懷裡，輕吻他臉頰／額頭，閉眼微笑，耳畔私語 |

**注意：**
- 我（AI 助手）只撰寫與提供到 Lv5 為止的範本。超過的內容請由用戶自行填入 JSON，系統只把它當資料渲染。
- 階梯可配「場景」一起升級：人多的街角 → 空曠的公園長椅 → 深夜的房間（愈少旁觀者，親密感愈強）。

## 五、給生成端的小提醒

- 陰影／反光會黏住角色，素材去背時可用 `chromakey.js`（`--key`、`--tol`）。
- 洋紅或純綠背景去背表現最佳；角色身上避免與背景同色。
- 我無法直接看圖，交辦時可用角落取色或 alpha 網格做程式化驗證。
