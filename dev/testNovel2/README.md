# TestNovel2 - 原生能量世界觀設定

## 專案簡介

這是一個基於「原生能量世界」的奇幻小說/遊戲世界觀設定專案。世界觀涵蓋從遠古石器時代到現代科技時代的萬年演變，核心概念是生命能量（東方稱「氣」，西方稱「瑪娜」）的發現與應用。

## 專案結構

### 根目錄檔案

- **`world-settings.json`** - 世界基本設定，包括能量系統、修煉方向、文化差異等核心概念
- **`energy-system.json`** - 能量系統詳細說明，涵蓋氣與瑪娜的轉換與應用
- **`timeline.json`** - 世界時間線，分為五個主要時代：遠古啟蒙期、體系建立期、鼎盛與碰撞期、工業革命期、統一能源時代
- **`technology.json`** - 科技演進歷史，展示能量技術如何與傳統科技融合
- **`index.html`** - 專案首頁，可能用於展示世界觀或互動式地圖
- **`story-outline.json`** - 完整故事大綱，涵蓋五個時代的故事架構與並行情節線

### 分類目錄

- **`characters/`** - 角色設定檔案
  - `yan.json` - 炎（Yan），修煉文明始祖
  - `ariya.json` - 艾莉婭（Ariya），魔法文明始祖

- **`factions/`** - 勢力與組織設定檔案
  - `factions.json` - 主要勢力設定，包括三大聯盟（東方聯盟、西方聯盟、中立聯盟）與地下勢力
  - `tribes.json` - 遠古部落設定，目前包含赤焰部落（修煉文明發源地）

- **`scenes/`** - 場景設定檔案（待開發）
  - 用於存放重要地點、戰場、遺跡等的詳細描述

- **`events/`** - 事件設定檔案
  - `historical-events.json` - 標誌性歷史事件，記錄推動世界觀演變的關鍵時刻

- **`items/`** - 物品設定檔案（待開發）
  - 用於存放武器、法寶、魔法物品、古代文物的設定

- **`tests/`** - 測試與驗證腳本
  - `validate-characters.js` - 角色設定驗證腳本

- **`.github/`** - GitHub 相關設定
  - `instructions/` - 專案開發規範與範本

## 世界觀核心概念

### 生命能量
- **東方「氣」**：內斂修煉，追求長壽與強大
- **西方「瑪娜」**：外放應用，操控自然與法術
- **統一認知**：現代稱為「生命能量」，成為標準化能源

### 文明演變
1. **遠古啟蒙期** (-10000~-7000)：本能感知能量，薩滿/巫師時代
2. **體系建立期** (-7000~-4000)：理論成型，宗門/學院萌芽
3. **鼎盛與碰撞期** (-4000~-1500)：文明巔峰，東西首次接觸
4. **工業革命期** (-1500~-200)：能量機械化，傳統修煉衰落
5. **統一能源時代** (-200~0)：完全科學化，能量成為日常能源

## 使用說明

### 開發規範
- 角色設定請參考 `.github/instructions/角色設定範本.instructions.md`
- 所有 JSON 檔案應遵循統一格式
- 新增設定前請檢查與既有世界觀的一致性

### 驗證工具
```bash
# 驗證角色設定
node tests/validate-characters.js

# 驗證 JSON 語法
node -e "require('./filename.json')"
```
