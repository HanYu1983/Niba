## 1. 專案概述

### 1.1 遊戲基本資料

| 項目 | 內容 |
|------|------|
| **遊戲名稱** | 富甲天下 |
| **遊戲類型** | 大富翁-like 策略棋盤遊戲 |
| **題材背景** | 日本戰國 × 中國三國時代（跨時空融合） |
| **目標平台** | PC（Windows / Mac） |
| **目標受眾** | 策略遊戲愛好者、大富翁類遊戲玩家、歷史題材粉絲 |
| **核心概念** | 在亂世中扮演主公，透過擲骰走棋、經營資源、招募武將、征戰領地，最終統一天下 |

### 1.2 遊戲願景

融合日本戰國與中國三國兩大歷史時代的武將與地圖，透過程序化生成技術讓每一局遊戲都有獨特的體驗。玩家在棋盤上移動、佔領格子、發展資源、招募武將、培養軍隊，體驗從一方諸侯成長為天下霸主的过程。

### 1.3 設計目標

- 每局遊戲地圖、武將、道具、裝備均由程序化生成，確保高重玩性
- 簡潔易上手的操作，但具備足夠的策略深度
- 資源管理（糧食、金錢、士兵）與武將養成並重
- 單局遊戲時間控制在 30~60 分鐘

## 2. 遊戲玩法

### 2.1 核心機制

#### 2.1.1 棋盤移動
- 玩家輪流擲骰子（1~6 點），依點數在棋盤上移動
- 棋盤為**閉環路線**（首尾相連），經過起點可獲得獎勵
- 棋盤格數：每局由程序化生成，約 24~40 格

#### 2.1.2 格子類型

| 格子類型 | 說明 |
|----------|------|
| **村落格** | 可與玩家建立友好度關係，透過交易、搶奪、攻占互動。占領后可發展為城池（詳見 2.1.3） |
| **資源格** | 隨機獲取少量資源，可指派武將加成（詳見 2.1.8） |
| **事件格** | 觸發隨機事件（正面或負面），可指派武將規避壞事件（詳見 2.1.9） |
| **武將格** | 可招募武將，招募費用受玩家聲望影響（詳見 2.1.10） |
| **商店格** | 可購買裝備（詳見 2.1.11） |
| **起點** | 經過可獲得獎勵（詳見 2.1.12） |

#### 2.1.3 村落互動系統

每個村落對**每位玩家**擁有獨立的友好度（0~100）。

**互動機制**：
- 所有互動指令都需要**指派一名武將**執行
- 消耗該武將的體力
- 成功率與效果由武將數值決定

| 互動方式 | 成功率 | 效果 | 友好度變化 | 主要影響屬性 |
|----------|--------|------|------------|--------------|
| **交易** | 高 | 低（少量資源交換） | +5~15（依交易規模） | 政治 |
| **搶奪** | 低 | 高（大量資源獲取） | -20~40（劇烈下降） | 武力 |
| **攻占** | 依戰鬥結果 | 依戰鬥結果 | 依戰鬥結果決定 | 武力、統率 |

**友好度效果**：

| 友好度區間 | 狀態 | 效果 |
|------------|------|------|
| 0~29 | 敵對 | 攻占時反抗力最強 |
| 30~59 | 中立 | 攻占時反抗力中等 |
| 60~89 | 友好 | 攻占時反抗力較弱，交易價格優惠 |
| 90~100 | 歸順 | 村落自動歸順，成為玩家領地，每回合產出資源 |

**攻占戰鬥機制**：
- 友好度越高，村落守軍的戰鬥力越低
- 攻占成功後，友好度重置為 50（中立）
- 攻占失敗後，友好度 -10

**搶奪後果**：
- 可立即獲得村落儲存的資源
- 友好度大幅下降，可能導致敵對狀態
- 若友好度降至 0，村落可能呼叫援軍或封鎖交易

**交易機制**：
- 可交換的資源：糧食 ↔ 金錢 ↔ 士兵
- 交易比例受友好度影響（友好度越高，比例越優惠）
- 每次交易可提升友好度，鼓勵長期經營關係

**村落發展為城池**：
- 村落被玩家占領（歸順或攻占成功）后，成為該玩家的領地
- 城池等級：村落 → 小城 → 大城 → 都城
- 每級城池提升：
  - 資源成長率（糧食、金錢產出增加）
  - 防禦力（被敵方攻占時反抗力增強）
  - 可駐守武將數量上限
- 升級條件：
  - 消耗金錢與糧食
  - 可能需要特定武將執行「開發」指令

**玩家領地互動**：
當玩家走到自己的領地時，可選擇以下指令：

| 指令 | 說明 | 消耗 | 主要影響屬性 |
|------|------|------|--------------|
| **開發** | 升級城池等級，提升資源產出與防禦 | 金錢、糧食、武將體力 | 政治 |
| **調度** | 將隨身資源與領地資源互相調配 | 無 | - |
| **休整** | 大幅回復指定武將的體力 | 無 | - |

**開發指令詳解**：
- 需要**指派一名武將**執行
- 消耗該武將的體力
- 開發效果（升級成功率、升級幅度）由武將的**政治**能力決定
- 政治能力越高，開發效果越好、消耗體力越少

**敵方領地互動**：
當玩家走到其他玩家的領地時，可選擇以下指令：

| 指令 | 說明 | 消耗 | 主要影響屬性 |
|------|------|------|--------------|
| **搶奪** | 雙方各派出 500 名士兵對戰，快速獲取資源 | 500 士兵、武將體力 | 武力 |
| **攻占** | 攻擊方指定士兵數量 vs 防守方全部士兵，爭奪領地 | 指定士兵、武將體力 | 武力、統率 |
| **策略** | 指定武將發動策略干擾敵方 | 武將體力 | 智力/統率 |

**策略指令詳解**：
- 指定一名武將發動策略，消耗該武將體力
- 成功率由武將對應屬性決定，發動前可預覽成功率
- 策略分為三大類別：

**【指定武將】類**：

| 策略名稱 | 效果 | 消耗體力 | 主要屬性 |
|----------|------|----------|----------|
| **鼓舞** | 回復指定武將體力 | 中 | 統率 |
| **激勵** | 指定武將下次指令效果提升 | 低 | 統率 |
| **療傷** | 回復指定武將體力並解除負面狀態 | 高 | 智力 |
| **覺醒** | 指定武將隨機一項能力暫時提升 | 高 | 智力 |

**【指定格子】類**：

| 策略名稱 | 效果 | 消耗體力 | 主要屬性 |
|----------|------|----------|----------|
| **火計** | 降低目標格子的士兵數量 | 中 | 智力 |
| **破壞** | 降低目標格子的城池等級 | 高 | 智力 |
| **屯田** | 提升目標格子下回合糧食產出 | 低 | 政治 |
| **商路** | 提升目標格子下回合金錢產出 | 低 | 政治 |
| **築城** | 提升目標格子的防禦力 | 中 | 政治 |

**【指定玩家】類**：

| 策略名稱 | 效果 | 消耗體力 | 主要屬性 |
|----------|------|----------|----------|
| **離間** | 降低目標玩家的武將忠誠度 | 中 | 智力 |
| **急襲** | 對目標玩家造成士兵損失 | 高 | 武力 |
| **流言** | 降低目標玩家的聲望 | 中 | 智力 |
| **徵兵** | 從目標玩家處獲取少量士兵 | 中 | 統率 |

**搶奪指令詳解**：
- 雙方各派出 **500 名士兵** 進行對戰
- 指定一名武將指揮
- 消耗 500 士兵與武將體力
- 勝利後可快速獲取敵方領地資源，但不改變領地所有權

**攻占指令詳解**：
- **攻擊方**：指定投入的士兵數量（可少於或多於 500）
- **防守方**：投入領地內的 **全部士兵**
- 雙方各指定一名武將指揮
- 消耗投入的士兵與武將體力
- 戰鬥成功率（勝率）由雙方武將的**武力**與**統率**能力決定
- 發動前可預覽勝率，讓玩家自行評估風險
- 勝率計算參考：
  - 攻擊方武將能力 vs 防守方武將能力
  - 防守方享有城池防禦加成
  - 城池等級越高，防守方優勢越大
- 攻占成功後，領地所有權轉移，原領地資源部分被掠奪

#### 2.1.3 資源系統

| 資源 | 用途 |
|------|------|
| **金錢** | 招募武將、購買道具裝備、升級城池 |
| **糧食** | 維持士兵消耗、行軍征戰、城池發展 |
| **士兵** | 戰鬥兵力，影響戰鬥勝負 |
| **武將** | 帶領士兵、裝備道具、擁有特殊技能 |

**資源分類**：

| 分類 | 說明 |
|------|------|
| **隨身資源** | 玩家（主公）身上攜帶的資源，可隨時使用，但可能被搶奪 |
| **領地資源** | 儲存在已佔領的城池/村落中，較安全，需回合結算時才能調用 |

**士兵消耗機制**：
- 每一個回合會根據士兵數目**少量**減少糧食
- 消耗公式：`每回合消耗 = 士兵數量 × 消耗係數（少量）`
- 糧食不足時，士兵依不足比例逃亡：
  - 若糧食僅夠 70% 需求 → 30% 士兵逃亡
  - 若糧食為 0 → 大量士兵逃亡（可能全軍覆沒）

#### 2.1.4 玩家狀態

| 狀態 | 說明 |
|------|------|
| **聲望** | 反映玩家的統治風格 |
| **隨身資源** | 金錢、糧食、士兵、武將 |
| **領地資源** | 儲存在各城池/村落中的資源 |

**聲望系統**：
- 執行正面行為（如交易、歸順村落）→ 聲望上升
- 執行負面行為（如搶奪、屠城）→ 聲望下降
- 聲望影響：
  - 武將招募成功率
  - 村落初始友好度
  - 特殊事件觸發機率

#### 2.1.5 武將系統

武將跟隨主公行動，可裝備道具、執行指令。

**體力系統**：
- 每位武將擁有體力值（0~100）
- 武將執行【指令】會消耗體力
- 武將的能力值會依據體力多寡增減：
  - 體力 80~100：能力 100%
  - 體力 50~79：能力 80%
  - 體力 20~49：能力 60%
  - 體力 0~19：能力 40%
- 每回合結束時，武將回復固定體力（如 +15）

**指令系統**：
- 武將可執行的指令類型：
  - **戰鬥指令**：攻擊、防禦、突襲（消耗體力，影響戰鬥結果）
  - **內政指令**：治理、開發、交易（消耗體力，提升領地產出）
  - **特殊指令**：武將專屬技能（消耗體力，觸發特殊效果）
- 指令效果受武將屬性（武力、統率、智力、政治）影響

**功績與職位系統**：
- 武將執行指令成功後獲得功績
- 功績累積可提升武將職位
- 職位提升帶來屬性加成與解鎖新指令
- 職位階級：士兵 → 伍長 → 什長 → 校尉 → 將軍 → 大將軍

#### 2.1.6 玩家指令

每回合玩家可選擇執行以下指令之一：

| 指令 | 說明 |
|------|------|
| **移動** | 擲骰子決定移動格數，觸發落點格子的事件（每回合僅限一次） |
| **策略** | 指定一名武將發動策略，消耗該武將體力，成功率由武將數值決定（可預覽成功率） |
| **武將** | 打開武將列表，查看武將詳細資訊（不消耗回合） |

**策略使用時機**：

策略分為兩個使用階段，**每個階段僅限使用一次**：

| 階段 | 說明 | 目標限制 | 使用次數 |
|------|------|----------|----------|
| **移動前** | 在擲骰移動前使用策略 | 可指定任意合法目標（武將、格子、玩家） | 每回合 1 次 |
| **移動後** | 在移動完成後、觸發格子事件前使用策略 | **一律針對所站格子**為對象 | 每回合 1 次 |

**移動前策略範例**：
- 【指定武將】鼓舞、激勵、療傷、覺醒
- 【指定格子】火計、破壞、屯田、商路、築城
- 【指定玩家】離間、急襲、流言、徵兵

**移動後策略範例**（針對所站格子）：
- 若站在己方領地：屯田、商路、築城、開發
- 若站在敵方領地：火計、破壞、潛入
- 若站在資源格：武將加成
- 若站在事件格：規避負面事件

**策略指令詳解**：
- 詳細策略設計請參閱 [策略系統.md](./策略系統.md)
- 玩家選擇一名武將，從可用策略列表中選擇要發動的策略
- 策略成功率由武將對應屬性決定（如智力型策略看智力、武力型策略看武力）
- 發動前可預覽成功率，讓玩家自行評估風險
- 策略類型範例：
  - **火計**：對敵方領地造成破壞（成功率受智力影響）
  - **離間**：降低敵方村落對敵方玩家的友好度（成功率受智力影響）
  - **鼓舞**：提升己方士兵士氣（成功率受統率影響）
  - **突襲**：對鄰近敵方玩家造成士兵損失（成功率受武力影響）

**武將指令詳解**：
- 打開武將列表，查看麾下所有武將的詳細資訊
- **不消耗回合**，可在任何時機查看
- 武將列表顯示每位武將的完整訊息：

| 欄位 | 說明 |
|------|------|
| **姓名** | 武將名稱 |
| **所屬時代** | 日本戰國 / 中國三國 |
| **稀有度** | 普通 / 精良 / 史詩 / 傳說 |
| **職位** | 士兵 → 伍長 → 什長 → 校尉 → 將軍 → 大將軍 |
| **武力** | 影響戰鬥攻擊力（1~100） |
| **統率** | 影響帶兵數量上限（1~100） |
| **智力** | 影響事件成功率與策略效果（1~100） |
| **政治** | 影響城池資源成長率加成（1~100） |
| **忠誠度** | 影響被敵方挖角的難度（1~100） |
| **體力** | 當前體力值（0~100） |
| **功績** | 累積功績值 |
| **裝備** | 已裝備的裝備列表 |
| **特殊技能** | 武將擁有的 1~2 個獨特技能 |

#### 2.1.7 格子資源成長率

每個格子（尤其是城池格）擁有獨立的資源成長率：

- **糧食成長率**：每回合自動增加的糧食產量
- **金錢成長率**：每回合自動增加的金錢產量
- **士兵成長率**：每回合自動增加的士兵數量
- 成長率受以下因素影響：
  - 格子基礎值（程序化生成）
  - 城池等級（可花費資源升級）
  - 駐守武將的能力值
  - 特殊道具加成

**地形系統**：
- 每個格子的地形由程序化生成
- 地形類型影響資源成長率：

| 地形類型 | 糧食成長率 | 金錢成長率 | 士兵成長率 |
|----------|------------|------------|------------|
| **平原** | 高 | 中 | 中 |
| **山地** | 低 | 高（礦產） | 低 |
| **森林** | 中 | 低 | 中 |
| **河川** | 高 | 中 | 低 |
| **海岸** | 低 | 高（貿易） | 低 |
| **草原** | 中 | 低 | 高（牧馬） |

> 地形類型與成長率數值可在開發階段調整

#### 2.1.8 資源格互動

玩家走到資源格時，觸發以下流程：

**基礎獎勵**：
- 隨機獲取少量資源（糧食、金錢、士兵其中之一或組合）
- 資源數量由程序化生成決定

**武將加成（可選）**：
- 玩家可選擇是否指派一名武將進行資源加成
- 若選擇加成：
  - 消耗該武將的體力
  - 根據武將能力增加獲取資源的數量
  - 加成參考屬性：
    - **政治**：增加金錢獲取量
    - **統率**：增加士兵獲取量
    - **智力**：增加糧食獲取量
- 若不選擇加成：
  - 不消耗體力，僅獲取基礎獎勵

#### 2.1.9 事件格互動

玩家走到事件格時，觸發隨機事件。事件分為正面事件與負面事件。

**正面事件範例**：

| 事件名稱 | 效果 |
|----------|------|
| **武將覺醒** | 指定一名武將隨機一項能力永久 +5 |
| **士氣高漲** | 所有武將體力 +20 |
| **天降糧草** | 獲得大量糧食 |
| **名將投靠** | 免費招募一名隨機武將 |

**負面事件範例**：

| 事件名稱 | 效果 |
|----------|------|
| **疫病流行** | 所有武將體力 -20，士兵減少 |
| **暗殺企圖** | 指定一名武將能力永久 -3 |
| **糧倉失火** | 損失大量糧食 |
| **叛逃事件** | 忠誠度最低的武將可能離開 |

**規避機制（負面事件）**：
- 發生負面事件時，玩家可選擇是否指派一名武將進行規避
- 若選擇規避：
  - 消耗該武將的體力
  - 根據武將能力顯示規避成功率
  - 玩家可預覽成功率後決定是否執行
  - 規避成功 → 事件效果減半或完全無效
  - 規避失敗 → 事件效果正常生效
- 若不選擇規避：
  - 不消耗體力，事件效果正常生效

**規避屬性對應**：

| 事件類型 | 規避主要屬性 |
|----------|--------------|
| 疫病流行 | 智力 |
| 暗殺企圖 | 武力 |
| 糧倉失火 | 政治 |
| 叛逃事件 | 統率 |

#### 2.1.10 武將格互動

玩家走到武將格時，僅可使用以下指令：

| 指令 | 說明 |
|------|------|
| **招募** | 打開招募清單，選擇是否招募武將 |
| **回合結束** | 結束本回合，不進行招募 |

**招募流程**：
- 點擊【招募】後，顯示當前可招募的武將清單（程序化生成 3~5 名）
- 每位武將顯示其屬性、稀有度、招募費用
- 玩家可選擇招募任意數量的武將（受金錢限制）
- 招募完成後，點擊【回合結束】結束本回合

**招募費用**：
- 基礎費用由武將的稀有度與能力值決定
- 最終費用受玩家**聲望**影響：

| 聲望區間 | 費用調整 |
|----------|----------|
| 高聲望 | 費用折扣（-20%~30%） |
| 中聲望 | 基礎費用 |
| 低聲望 | 費用增加（+20%~50%） |

**聲望影響招募的原因**：
- 高聲望代表玩家名聲顯赫，武將更願意投靠，因此費用較低
- 低聲望代表玩家名聲不佳，需要花費更多金錢才能說服武將加入

#### 2.1.11 商店格互動

玩家走到商店格時，可購買裝備。

**裝備系統**：
- 詳細裝備設計請參閱 [裝備系統.md](./裝備系統.md)
- 裝備只能裝備在武將身上
- 裝備後，武將獲得屬性加成
- 裝備時，武將的**忠誠度提升**
- **裝備一旦裝上，不可拆下**

**商店流程**：
- 顯示當前可購買的裝備列表（程序化生成 3~5 件）
- 每件裝備顯示其加成屬性、稀有度、價格
- 玩家選擇購買後，可立即裝備給指定武將

**裝備類型範例**：

| 裝備類型 | 加成屬性 | 範例 |
|----------|----------|------|
| **武器** | 武力 | 村正、青龍偃月刀 |
| **防具** | 統率 | 當世具足、明光鎧 |
| **兵法書** | 智力 | 孫子兵法、六韜 |
| **政書** | 政治 | 貞觀政要、論語 |

**忠誠度提升規則**：
- 裝備稀有度越高，忠誠度提升越多
- 普通裝備：忠誠度 +5
- 精良裝備：忠誠度 +10
- 史詩裝備：忠誠度 +15
- 傳說裝備：忠誠度 +20

#### 2.1.12 起點獎勵

玩家走回起點時，觸發以下流程：

**聲望獎勵**：
- 根據玩家的**聲望**等級，獲得相應資源：

| 聲望等級 | 獎勵內容 |
|----------|----------|
| 高聲望 | 大量金錢 + 糧食 + 士兵 |
| 中聲望 | 中量金錢 + 糧食 |
| 低聲望 | 少量金錢 |

**領地資源成長**：
- 所有玩家擁有的領地根據格子上的**資源成長率**進行一次資源成長
- 每座領地依據其地形與城池等級，自動增加儲存的資源：
  - 糧食成長率 → 增加糧食
  - 金錢成長率 → 增加金錢
  - 士兵成長率 → 增加士兵
- 成長後的資源存入領地資源庫，玩家可透過【調度】指令調配

### 2.2 遊戲循環

```
選擇指令 → [移動] 擲骰移動 → 觸發格子事件 → 管理資源/武將 → 結束回合
         → [策略] 指定武將發動 → 判定成功率 → 執行效果 → 結束回合
         → [休整] 回復全體體力 → 結束回合
                                                      ↓
                                              AI對手回合 → 回到玩家回合
```

### 2.3 玩家目標

- **短期目標**：佔領更多城池、累積資源、招募強力武將
- **中期目標**：升級領地、組建強大軍隊、削弱對手
- **長期目標**：消滅所有對手或達成特定勝利條件（如佔領指定數量的城池）

### 2.4 勝利條件

1. **征服勝利**：消滅所有對手的全部士兵
2. **領土勝利**：佔領超過半數的城池格
3. **財富勝利**：累積達到指定金額（如 100,000 金）
4. **時限勝利**：達到指定回合數時，綜合評分最高者勝

### 2.5 遊戲模式

- **單機模式**：1 名玩家 vs 3 名 NPC 電腦玩家
- 共 4 名主公在棋盤上爭霸
- NPC 電腦玩家會根據難度等級執行不同的策略

### 2.6 難度設計

- AI 難度分級：簡單 / 普通 / 困難
- 起點資源量依難度調整
- **初始資源**（普通難度）：
  - 金錢：1000
  - 士兵：1000
  - 糧食：1000
- **初始武將**：
  - 遊戲初始時，每位玩家（包含 NPC）隨機獲得 **4 名武將**
- NPC 行為邏輯依難度變化：
  - **簡單**：NPC 決策較隨機，資源管理效率低
  - **普通**：NPC 有基本策略，會優先發展領地
  - **困難**：NPC 積極擴張，善於使用策略與攻占

## 3. 故事與世界觀

### 3.1 背景設定

在一個時空錯亂的異世界中，日本戰國時代與中國三國時代的時空裂縫交織在一起。織田信長與曹操、武田信玄與諸葛亮……這些原本不屬於同一時代的英雄豪傑，在同一個棋盤世界上演全新的爭霸故事。

### 3.2 角色設定

#### 3.2.1 可選主公（玩家角色）

| 主公 | 所屬勢力 | 初始優勢 |
|------|----------|----------|
| 織田信長 | 日本戰國 | 初始金錢較高 |
| 曹操 | 中國三國 | 初始士兵較多 |
| 武田信玄 | 日本戰國 | 初始武將能力較高 |
| 劉備 | 中國三國 | 初始糧食較多 |
| 德川家康 | 日本戰國 | 城池成長率加成 |
| 孫權 | 中國三國 | 招募武將費用折扣 |

> 更多主公將在後續版本中擴充

#### 3.2.2 武將（程序化生成）

武將由程序化生成系統產生，每個武將包含：

| 屬性 | 說明 | 數值範圍 |
|------|------|----------|
| **姓名** | 從兩大時代的武將名庫中組合 | - |
| **所屬時代** | 日本戰國 / 中國三國 | - |
| **武力** | 影響戰鬥攻擊力 | 1~100 |
| **統率** | 影響帶兵數量上限 | 1~100 |
| **智力** | 影響事件成功率與策略效果 | 1~100 |
| **政治** | 影響城池資源成長率加成 | 1~100 |
| **忠誠度** | 影響被敵方挖角的難度 | 1~100 |
| **特殊技能** | 每位武將擁有 1~2 個獨特技能 | 程序化生成 |
| **稀有度** | 普通 / 精良 / 史詩 / 傳說 | - |

### 3.3 世界設計

- 每局遊戲的地圖由程序化生成
- 地圖主題風格隨機選取：日本戰國風 / 中國三國風 / 融合風
- 地圖上的城池名稱來自兩大時代的真實地名

## 6. 技術規格

### 6.1 程序化生成系統

#### 6.1.1 地圖生成
- 使用隨機種子（Seed）控制生成結果
- 支援種子碼分享，讓玩家可重複遊玩特定地圖

- 屬性分配：基於稀有度決定屬性總和，再隨機分配
- 技能生成：從技能庫中隨機組合，確保平衡性

#### 6.1.3 裝備生成
- 裝備：可裝備在武將身上（如「村正」、「青龍偃月刀」）
- 屬性加成與稀有度掛鉤
