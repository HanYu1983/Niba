## 1. 主指令（每回合二選一）

每回合玩家可從以下兩個指令中選擇**一個**執行：

| 指令 | 說明 | 消耗回合 |
|------|------|----------|
| **移動** | 擲骰子移動，觸發落點格子事件 | ✅ |
| **策略** | 指定武將發動策略 | ✅ |

> **【武將】指令**不消耗回合，可在任何時機查看。

---

## 2. 移動指令流程

### 2.1 基本流程

```
點擊【移動】
    ↓
播放擲骰動畫（1~6 點）
    ↓
玩家棋子移動對應格數
    ↓
判定是否經過起點 → 是 → 觸發起點獎勵（見 5.1）
    ↓
判定落點格子類型
    ↓
觸發對應格子事件（見第 3 節）
```

### 2.2 移動後格子事件

移動完成後，直接觸發落點格子的對應事件（見第 3 節）。

> **注意**：為降低遊戲複雜度，移動後不再提供策略使用選項，玩家需在移動前決定是否使用策略指令。

## 3. 格子事件流程

### 3.1 村落格（第三方勢力）

```
走到村落格
    ↓
顯示村落資訊（名稱、地形、資源、友好度）
    ↓
顯示可選指令：
    ├─ 【交易】→ 選擇武將 → 顯示成功率 → 確認 → 執行交易 → 友好度 +5~15
    ├─ 【搶奪】→ 選擇武將 → 顯示成功率 → 確認 → 執行搶奪 → 友好度 -20~40
    └─ 【攻占】→ 選擇武將 → 選擇士兵數 → 顯示勝率 → 確認 → 進入戰鬥
```

### 3.2 己方領地（已占領村落/城池）

```
走到己方領地
    ↓
顯示領地資訊（名稱、等級、地形、資源儲存量）
    ↓
顯示可選指令：
    ├─ 【開發】→ 選擇武將 → 消耗金錢/糧食/體力 → 判定成功率 → 升級城池
    ├─ 【調度】→ 打開資源調度介面 → 選擇調配方向與數量 → 確認
    └─ 【休整】→ 選擇武將 → 回復大量體力（+40）
```

### 3.3 敵方領地

```
走到敵方領地
    ↓
顯示領地資訊（名稱、等級、地形、所屬玩家、資源儲存量）
    ↓
顯示可選指令：
    ├─ 【搶奪】→ 選擇武將 → 雙方各派 500 士兵 → 顯示勝率 → 確認 → 進入戰鬥
    └─ 【攻占】→ 選擇武將 → 選擇投入士兵數 → 顯示勝率 → 確認 → 進入戰鬥
```

### 3.4 武將格

```
走到武將格
    ↓
顯示可選指令：
    ├─ 【招募】→ 打開招募清單（3~5 名武將）
    │              ↓
    │           顯示每位武將：姓名、時代、稀有度、屬性、費用
    │              ↓
    │           玩家選擇招募（可招募多名，受金錢限制）
    │              ↓
    │           確認招募 → 扣除金錢 → 武將加入
    │
    └─ 【回合結束】→ 結束本回合
```

### 3.5 商店格

```
走到商店格
    ↓
打開商店介面
    ↓
顯示可購買裝備清單（3~5 件）
    ↓
顯示每件裝備：名稱、類型、稀有度、加成屬性、價格
    ↓
玩家選擇購買 → 扣除金錢 → 選擇裝備給哪位武將 → 裝備生效、忠誠度提升
    ↓
可繼續購買或關閉商店 → 結束本回合
```

### 3.6 資源格

```
走到資源格
    ↓
顯示基礎獎勵（隨機資源：糧食/金錢/士兵）
    ↓
詢問是否指派武將加成？
    ├─ 是 → 選擇武將 → 消耗體力 → 根據屬性加成資源 → 獲得資源
    └─ 否 → 獲得基礎獎勵
    ↓
結束本回合
```

### 3.7 事件格

```
走到事件格
    ↓
觸發隨機事件
    ↓
顯示事件內容與效果
    ↓
if 正面事件:
    直接套用效果
    結束本回合
else:  # 負面事件
    詢問是否指派武將規避？
    ├─ 是 → 選擇武將 → 消耗體力 → 顯示規避成功率 → 確認
    │         ↓
    │      判定成功/失敗
    │         ├─ 成功 → 事件效果減半或無效
    │         └─ 失敗 → 事件效果正常生效
    └─ 否 → 事件效果正常生效
    ↓
    結束本回合
```

### 3.8 起點

```
經過起點
    ↓
觸發聲望獎勵：
    ├─ 高聲望（>=70）→ 金錢 +300、糧食 +200、士兵 +200
    ├─ 中聲望（40~69）→ 金錢 +200、糧食 +150
    └─ 低聲望（<40）→ 金錢 +100
    ↓
觸發領地資源成長：
    所有領地根據資源成長率增加資源
    ↓
繼續移動剩餘步數（如有）
```

## 4. 策略指令流程

### 4.1 移動前策略流程

```
點擊【策略】（移動前）
    ↓
選擇發動策略的武將
    ↓
顯示可用策略列表（依職位解鎖）
    ↓
選擇策略類型：
    ├─ 【指定武將】→ 選擇目標武將 → 顯示成功率 → 確認 → 執行
    ├─ 【指定格子】→ 選擇目標格子 → 顯示成功率 → 確認 → 執行
    └─ 【指定玩家】→ 選擇目標玩家 → 顯示成功率 → 確認 → 執行
    ↓
消耗武將體力
    ↓
判定成功/失敗
    ↓
執行效果
    ↓
回到主指令選擇（可選擇移動/休整）
```

## 5. 武將指令流程（不消耗回合）

```
點擊【武將】
    ↓
打開武將列表
    ↓
顯示每位武將的完整資訊：
    - 姓名、所屬時代、稀有度、職位
    - 武力、統率、智力、政治、忠誠度
    - 體力（含體力條）、功績
    - 已裝備裝備列表
    - 特殊技能
    ↓
玩家可關閉列表，回到主指令選擇
```

## 8. 彈窗流程設計

> **設計目標**：確保玩家能清晰感知所有狀態變化，包括自身操作結果與AI行為影響。

### 7.1 彈窗系統概述

彈窗系統用於向玩家展示**重要狀態變化**、**關鍵事件結果**和**AI行為通知**。所有彈窗遵循以下原則：

- **即時性**：狀態變化發生後立即顯示
- **清晰性**：內容簡潔明瞭，重點突出
- **可追溯**：重要變化可在日誌中回顧
- **非打斷**：次要通知可自動消失，不阻斷遊戲流程

### 7.2 彈窗類型分類

| 彈窗類型 | 觸發時機 | 顯示方式 | 消失方式 | 優先級 |
|----------|----------|----------|----------|--------|
| **確認彈窗** | 需要玩家確認操作 | 居中模態 | 玩家點擊確認/取消 | 最高 |
| **結果彈窗** | 操作完成後顯示結果 | 居中模態 | 玩家點擊關閉 | 高 |
| **戰鬥彈窗** | 戰鬥開始/結束 | 全屏/居中 | 玩家點擊關閉 | 高 |
| **事件彈窗** | 隨機事件觸發 | 居中模態 | 玩家點擊關閉 | 高 |
| **AI通知** | AI執行重要操作 | 側邊/頂部 | 3秒自動消失 | 中 |
| **資源變化** | 資源增減 | 頂部浮動 | 2秒自動消失 | 中 |
| **提示彈窗** | 一般提示信息 | 底部浮動 | 2秒自動消失 | 低 |

### 7.3 彈窗觸發時機與流程

#### 7.3.1 玩家操作確認彈窗

```
玩家執行操作（如招募、攻占、交易等）
    ↓
顯示確認彈窗：
    ├─ 標題：操作名稱（如「確認招募」）
    ├─ 內容：操作詳情（武將名稱、消耗資源、預期效果）
    ├─ 按鈕：【確認】、【取消】
    └─ 點擊【確認】→ 執行操作 → 顯示結果彈窗
       點擊【取消】→ 關閉彈窗 → 回到操作前狀態
```

**示例：招募武將確認彈窗**
```
┌─────────────────────────────┐
│       確認招募              │
├─────────────────────────────┤
│ 武將：趙雲（三國時代）      │
│ 稀有度：★★★★☆              │
│ 招募費用：500 金錢          │
│                             │
│ 確定要招募此武將嗎？        │
├─────────────────────────────┤
│      [取消]    [確認]       │
└─────────────────────────────┘
```

#### 7.3.2 操作結果彈窗

```
操作執行完成
    ↓
顯示結果彈窗：
    ├─ 標題：操作結果（如「招募成功」、「攻占失敗」）
    ├─ 內容：詳細結果（獲得/損失資源、狀態變化）
    ├─ 視覺：成功（綠色）、失敗（紅色）、中立（藍色）
    └─ 按鈕：【確認】→ 關閉彈窗 → 繼續遊戲
```

**示例：資源變化結果彈窗**
```
┌─────────────────────────────┐
│       交易成功 ✓            │
├─────────────────────────────┤
│ 與「桃源村」交易完成        │
│                             │
│ 獲得：                      │
│   糧食 +150                 │
│   友好度 +10                │
│                             │
│ 消耗：                      │
│   金錢 -200                 │
├─────────────────────────────┤
│          [確認]             │
└─────────────────────────────┘
```

#### 7.3.3 戰鬥流程彈窗

```
戰鬥觸發（攻占/搶奪）
    ↓
顯示戰鬥準備彈窗：
    ├─ 標題：「戰鬥開始」
    ├─ 內容：雙方兵力、武將、地形加成
    ├─ 按鈕：【開始戰鬥】、【撤退】
    └─ 點擊【開始戰鬥】→ 進入戰鬥動畫/計算
       點擊【撤退】→ 關閉彈窗 → 回到操作前狀態
    ↓
戰鬥結束
    ↓
顯示戰鬥結果彈窗：
    ├─ 標題：「戰鬥結果」
    ├─ 內容：勝負、損失兵力、獲得資源
    ├─ 視覺：勝利（金色）、失敗（灰色）
    └─ 按鈕：【確認】→ 關閉彈窗 → 繼續遊戲
```

#### 7.3.4 隨機事件彈窗

```
走到事件格/觸發隨機事件
    ↓
顯示事件彈窗：
    ├─ 標題：事件名稱（如「天災」、「奇遇」）
    ├─ 內容：事件描述、影響範圍
    ├─ 視覺：正面（金色）、負面（暗紅色）
    ├─ 按鈕：【確認】（正面事件）
    └─ 按鈕：【確認】、【指派武將規避】（負面事件）
    ↓
if 選擇規避：
    顯示規避結果彈窗
else:
    直接套用事件效果
    ↓
關閉彈窗 → 繼續遊戲
```

### 7.4 AI行為通知流程

> **設計理由**：玩家需了解AI對手的行動，以便制定策略，但AI通知不應過度打斷遊戲節奏。

#### 7.4.1 AI重要操作通知

```
AI執行重要操作（攻占、策略、交易等）
    ↓
顯示AI通知彈窗（側邊或頂部）：
    ├─ 標題：AI玩家名稱 + 操作類型
    ├─ 內容：操作詳情（目標、結果）
    ├─ 視覺：AI代表色邊框
    ├─ 顯示時間：3秒
    └─ 自動消失 → 可點擊查看詳情
```

**示例：AI攻占通知**
```
┌─────────────────────────────┐
│ ⚔️ AI-曹操 攻占了「洛陽城」 │
│ 兵力損失：300               │
│ [查看詳情]                  │
└─────────────────────────────┘
```

#### 7.4.2 AI回合開始/結束通知

```
AI回合開始
    ↓
顯示回合通知（頂部）：
    ├─ 內容：「AI-XXX 的回合」
    ├─ 顯示時間：1.5秒
    └─ 自動消失
    ↓
AI執行操作（可顯示簡化通知，見 7.4.1）
    ↓
AI回合結束
    ↓
顯示回合通知（頂部）：
    ├─ 內容：「AI-XXX 回合結束」
    ├─ 顯示時間：1秒
    └─ 自動消失 → 回到玩家回合
```

#### 7.4.3 AI策略使用通知

```
AI使用策略
    ↓
顯示策略通知（側邊）：
    ├─ 標題：「AI-XXX 使用了策略」
    ├─ 內容：策略名稱、目標、效果
    ├─ 顯示時間：3秒
    └─ 自動消失
```

### 7.5 資源變化浮動提示

```
資源發生變化（任何來源）
    ↓
顯示浮動提示（頂部資源欄附近）：
    ├─ 格式：「資源名稱 +數值」或「資源名稱 -數值」
    ├─ 顏色：增加（綠色）、減少（紅色）
    ├─ 動畫：從資源欄浮出，向上飄動後消失
    ├─ 顯示時間：2秒
    └─ 多個變化時依次顯示，不重疊
```

**示例：**
```
金錢 +300 ↑（綠色，向上飄動）
糧食 -100 ↓（紅色，向上飄動）
士兵 +150 ↑（綠色，向上飄動）
```

### 7.6 彈窗優先級與隊列管理

```
多個彈窗同時觸發
    ↓
按優先級排序：
    1. 確認彈窗（最高）
    2. 結果彈窗/戰鬥彈窗/事件彈窗
    3. AI通知
    4. 資源變化提示
    5. 提示彈窗（最低）
    ↓
高優先級彈窗顯示時：
    ├─ 低優先級彈窗進入隊列
    ├─ 同優先級按觸發時間排序
    └─ 自動消失類彈窗超時後自動移除
    ↓
當前彈窗關閉後：
    └─ 從隊列取出下一個彈窗顯示
```

### 7.7 彈窗交互設計規範

| 取消 | 取消操作 | 灰色 | 左側 |

|--------|------|

### 7.8 彈窗日誌系統

```
所有彈窗內容同步記錄到日誌
    ↓

    ├─ 點擊【日誌】按鈕
    ├─ 顯示歷史事件列表（按時間倒序）
    ├─ 每條記錄：時間、類型、內容
    └─ 可篩選：玩家操作、AI操作、事件、戰鬥
```

### 7.10 測試方案

| 測試項目 | 測試方法 | 驗證標準 |
|----------|----------|----------|
| 彈窗觸發時機 | 執行各類操作 | 彈窗在正確時機顯示 |
| 彈窗優先級 | 同時觸發多個彈窗 | 高優先級彈窗先顯示 |

| 自動消失時間 | 計時觀察 | 通知在設定時間內消失 |
