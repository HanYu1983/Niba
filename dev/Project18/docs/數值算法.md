## 2. 搶奪機率算法

### 2.1 搶奪戰鬥流程

```
雙方各派出 500 名士兵
    ↓
指定武將指揮
    ↓
計算攻擊方戰力
    ↓
計算防守方戰力
    ↓
比較戰力 → 判定勝負
```

### 2.2 戰力計算公式

**攻擊方戰力**：
```
攻擊戰力 = 500 × (武力係數 + 統率係數) × 體力修正 × 隨機係數

其中：
武力係數 = 攻擊武將武力 / 100
統率係數 = 攻擊武將統率 / 100 × 0.5
體力修正 = 根據體力區間查表（見 1.5）
隨機係數 = 0.85 ~ 1.15（隨機浮動）
```

**防守方戰力**：
```
防守戰力 = 500 × (武力係數 + 統率係數) × 體力修正 × 城池防禦加成 × 隨機係數

其中：
武力係數 = 防守武將武力 / 100
統率係數 = 防守武將統率 / 100 × 0.5
體力修正 = 根據體力區間查表（見 1.5）
城池防禦加成 = 1 + (城池等級 - 1) × 0.15
隨機係數 = 0.85 ~ 1.15（隨機浮動）
```

### 2.3 勝負判定

```
if 攻擊戰力 > 防守戰力:
    攻擊方勝利
    獲取敵方領地資源（比例 = (攻擊戰力 - 防守戰力) / 攻擊戰力 × 50%）
    不改變領地所有權
else:
    防守方勝利
    攻擊方損失部分士兵（損失比例 = (防守戰力 - 攻擊戰力) / 防守戰力 × 30%）
```

### 2.4 搶奪成功率（預覽用）

```
預估成功率 = 攻擊戰力(無隨機) / (攻擊戰力(無隨機) + 防守戰力(無隨機)) × 100%
```

## 3. 攻占機率算法

### 3.1 攻占戰鬥流程

```
攻擊方指定士兵數量
防守方投入全部士兵
    ↓
指定武將指揮
    ↓
計算攻擊方戰力
    ↓
計算防守方戰力
    ↓
比較戰力 → 判定勝負
```

### 3.2 戰力計算公式

**攻擊方戰力**：
```
攻擊戰力 = 攻擊士兵數 × (武力係數 + 統率係數) × 體力修正 × 隨機係數

其中：
武力係數 = 攻擊武將武力 / 100
統率係數 = 攻擊武將統率 / 100 × 0.5
體力修正 = 根據體力區間查表（見 1.5）
隨機係數 = 0.85 ~ 1.15（隨機浮動）
```

**防守方戰力**：
```
防守戰力 = 防守士兵數 × (武力係數 + 統率係數) × 體力修正 × 城池防禦加成 × 友好度修正 × 隨機係數

其中：
武力係數 = 防守武將武力 / 100
統率係數 = 防守武將統率 / 100 × 0.5
體力修正 = 根據體力區間查表（見 1.5）
城池防禦加成 = 1 + (城池等級 - 1) × 0.15
友好度修正 = 1 + (100 - 友好度) / 100 × 0.3
隨機係數 = 0.85 ~ 1.15（隨機浮動）
```

### 3.3 勝負判定

```
if 攻擊戰力 > 防守戰力:
    攻占成功
    領地所有權轉移
    原領地資源部分被掠奪（掠奪比例 = 30%）
    友好度重置為 50
else:
    攻占失敗
    攻擊方損失士兵（損失比例 = 攻擊士兵數 × 20%）
    友好度 -10
```

### 3.4 攻占勝率（預覽用）

```
預估勝率 = 攻擊戰力(無隨機) / (攻擊戰力(無隨機) + 防守戰力(無隨機)) × 100%
```

## 4. 策略成功率算法

### 4.1 基本公式

```
成功率 = (武將對應屬性 / 100) × 基礎成功率 × 體力修正 × 100%

其中：
基礎成功率：
  - 低消耗策略：80%
  - 中消耗策略：60%
  - 高消耗策略：40%

體力修正 = 根據體力區間查表（見 1.5）
```

### 4.2 各策略成功率計算

| 策略 | 對應屬性 | 基礎成功率 | 範例計算（屬性 70，體力 85） |
|------|----------|------------|------------------------------|
| 鼓舞 | 統率 | 60% | 0.7 × 0.6 × 1.0 = 42% |
| 激勵 | 統率 | 80% | 0.7 × 0.8 × 1.0 = 56% |
| 療傷 | 智力 | 40% | 0.7 × 0.4 × 1.0 = 28% |
| 覺醒 | 智力 | 40% | 0.7 × 0.4 × 1.0 = 28% |
| 火計 | 智力 | 60% | 0.7 × 0.6 × 1.0 = 42% |
| 破壞 | 智力 | 40% | 0.7 × 0.4 × 1.0 = 28% |
| 屯田 | 政治 | 80% | 0.7 × 0.8 × 1.0 = 56% |
| 商路 | 政治 | 80% | 0.7 × 0.8 × 1.0 = 56% |
| 築城 | 政治 | 60% | 0.7 × 0.6 × 1.0 = 42% |
| 離間 | 智力 | 60% | 0.7 × 0.6 × 1.0 = 42% |
| 急襲 | 武力 | 40% | 0.7 × 0.4 × 1.0 = 28% |
| 流言 | 智力 | 60% | 0.7 × 0.6 × 1.0 = 42% |
| 徵兵 | 統率 | 60% | 0.7 × 0.6 × 1.0 = 42% |

### 4.3 策略效果計算

```
if 策略成功:
    效果 = 基礎效果 × (武將對應屬性 / 100) × 體力修正
else:
    效果 = 0（或基礎效果的 25%，視策略類型而定）
```

## 5. 村落互動算法

### 5.1 交易成功率

```
成功率 = 基礎成功率(90%) + (政治 / 100) × 10% × 體力修正
```

### 5.2 搶奪（村落）成功率

```
成功率 = 基礎成功率(30%) + (武力 / 100) × 20% × 體力修正
```

### 5.3 攻占（村落）守軍戰力

```
守軍戰力 = 基礎守軍 × 友好度修正 × 隨機係數

其中：
基礎守軍 = 100 + 城池等級 × 50
友好度修正 = 1 + (100 - 友好度) / 100 × 0.5
隨機係數 = 0.85 ~ 1.15
```

## 6. 資源成長算法

### 6.1 每回合資源成長

```
糧食成長 = 基礎糧食成長率 × 地形係數 × 城池等級係數 × 武將政治加成
金錢成長 = 基礎金錢成長率 × 地形係數 × 城池等級係數 × 武將政治加成
士兵成長 = 基礎士兵成長率 × 地形係數 × 城池等級係數

其中：
地形係數（見 GDD 2.1.7）：
  - 平原：糧食 1.5、金錢 1.0、士兵 1.0
  - 山地：糧食 0.5、金錢 1.5、士兵 0.5
  - 森林：糧食 1.0、金錢 0.5、士兵 1.0
  - 河川：糧食 1.5、金錢 1.0、士兵 0.5
  - 海岸：糧食 0.5、金錢 1.5、士兵 0.5
  - 草原：糧食 1.0、金錢 0.5、士兵 1.5

城池等級係數：
  - 村落(1)：1.0
  - 小城(2)：1.3
  - 大城(3)：1.6
  - 都城(4)：2.0

武將政治加成 = 1 + (駐守武將政治 / 100) × 0.3
```

### 6.2 士兵消耗算法

```
每回合糧食消耗 = 士兵總數 × 消耗係數

消耗係數 = 0.01（即每 100 士兵消耗 1 糧食）

糧食不足時：
  需求比例 = 當前糧食 / 需求糧食
  if 需求比例 < 1:
      士兵逃亡比例 = (1 - 需求比例) × 0.5
      逃亡士兵數 = 士兵總數 × 士兵逃亡比例
```

## 7. 聲望算法

### 7.1 聲望變化

| 行為 | 聲望變化 |
|------|----------|
| 交易（村落） | +2~5 |
| 歸順村落 | +10 |
| 搶奪（村落） | -5~10 |
| 攻占成功 | -3 |
| 使用流言策略 | -5 |
| 使用離間策略 | -3 |

### 7.2 聲望影響

**招募費用調整**：
```
if 聲望 >= 70:
    費用折扣 = 0.7 ~ 0.8
elif 聲望 >= 40:
    費用折扣 = 1.0
else:
    費用折扣 = 1.2 ~ 1.5

最終費用 = 基礎費用 × 費用折扣
```

**起點獎勵**：
```
if 聲望 >= 70:
    金錢獎勵 = 300
    糧食獎勵 = 200
    士兵獎勵 = 200
elif 聲望 >= 40:
    金錢獎勵 = 200
    糧食獎勵 = 150
    士兵獎勵 = 0
else:
    金錢獎勵 = 100
    糧食獎勵 = 0
    士兵獎勵 = 0
```

| 稀有度 | 忠誠度提升 |
|--------|------------|
| 普通 | +5 |
| 精良 | +10 |
| 史詩 | +15 |
| 傳說 | +20 |

### 8.3 裝備程序化生成

```
生成裝備時：
  1. 根據遊戲進度決定稀有度權重
  2. 隨機選擇裝備類型（武器/防具/兵法書/政書）
  3. 從該類型的裝備庫中隨機選擇
  4. 屬性加成 = 基礎值 + 隨機浮動(±10%)
  5. 價格 = 基礎價格 × 稀有度係數 × (1 + 屬性浮動比例)
```

## 9. 武將生成算法

### 9.1 屬性分配

```
根據稀有度決定屬性總和：
  - 普通：總和 150~250
  - 精良：總和 250~350
  - 史詩：總和 350~450
  - 傳說：總和 450~500

屬性分配：
  1. 隨機決定主屬性（武力/統率/智力/政治之一）
  2. 主屬性 = 總和 × (0.3~0.4)
  3. 其餘三屬性 = 剩餘總和隨機分配
  4. 每項屬性最小值 = 10
```

### 9.2 初始武將生成

```
遊戲開始時，每位玩家獲得 4 名武將：
  - 1 名精良
  - 2 名普通
  - 1 名隨機（普通或精良）
```

## 11. 事件規避算法

```
規避成功率 = (武將對應屬性 / 100) × 基礎成功率 × 體力修正 × 100%

其中：
基礎成功率 = 50%
體力修正 = 根據體力區間查表（見 1.5）

if 規避成功:
    事件效果減半（或完全無效，視事件類型）
else:
    事件效果正常生效
```
