# semantic kernel 熱門新聞摘要

## 1. Microsoft's Semantic Kernel SDK Ships with AI Agents, Plugins, Planners and Personas

Microsoft的開源AI SDK Semantic Kernel已發布v1.0.1版本。新版本提供了新文件說明SDK的功能，能夠創建可與用戶互動、回答問題、調用現有代碼、自動化流程的AI代理。

來源：[Visual Studio Magazine](https://visualstudiomagazine.com/articles/2023/12/19/semantic-kernel-v1.aspx?p=1)

## 2. Elastic Brings Hybrid Retrieval to Microsoft Semantic Kernel

Elastic宣布其混合檢索功能可用於Microsoft的Semantic Kernel專案，使Elastic的向量資料庫成為首個具備此功能的產品。這項整合增強了Semantic Kernel的檢索能力。

來源：[Business Wire](https://www.businesswire.com/news/home/20250521382842/en/Elastic-Brings-Hybrid-Retrieval-to-Microsoft-Semantic-Kernel)
